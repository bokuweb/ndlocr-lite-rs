# Latinの上点と本文画線の所有関係

## 実装前の仕様：純粋kernelのみ

既存のraw正読残差では Agjp の j の点が独立成分になり、文字数との対応が崩れる。
さらにascender/descenderによって本文の共通高さが短くなる。最初の段階では、
点とstemの対応だけを小さな純粋kernelで扱う。推論・製品sanitize・認識結果を変更しない。
単語/文書別置換は導入しない。次のmarker/本文配置policyと追加対照は別仕様で先行する。

kernelは半開矩形と実前景面積を持つ1個の点候補、順序付きstem候補、本文基準高Hを受け取る。
唯一の所有stemのindexだけを返し、入力矩形/画素を変更しない。RGBからの成分抽出・
ノイズ除外・文字列との対応はこのkernelに含めず、この結果だけで文字を保持しない。

- Hは8以上。矩形は正の幅/高さ、面積は3以上で矩形面積以下。不正値/算術overflowは拒否する。
- 点の幅と高さはそれぞれ ceil(H/8)以上、floor(H/3)以下。
- 所有stemの高さは ceil(3H/4)以上、H以下。幅は ceil(H/8)以上、floor(3H/2)以下。
- 点はstemの上にあり、垂直gapは1以上ceil(H/4)以下。
- 水平共通幅は点幅の半分以上。点の水平中心（座標和を使用）がstemの水平範囲内。
- 点の面積の2倍はstemの面積以下。点上端からstem下端までの全高はfloor(3H/2)以下。
- 上記を満たすstemがちょうど1個の場合だけindexを返す。複数候補は先頭を選ばず拒否する。
  所有以外のstemも不正矩形/面積であってはならない。

先に点の大小/高さ/面積/上下gap/水平重なり/中心/曖昧な所有/不正入力の例示テストを追加し、
Red→Greenを確認する。移動とHの範囲に対する性質テストも使う。
実画素の抽出・marker形状・本文間隔・小文字高のpolicyは、このkernelの結果と分離して検証する。
固定したkernelの条件を将来の追加NN結果に合わせ直さない。
