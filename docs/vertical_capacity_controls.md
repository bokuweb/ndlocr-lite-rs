# 縦列容量回復候補の追加対照

## 描画・転記・この対照のNN前の仕様

支持mask H2は旧9列の30モデル4組で、既存の幾何/原結果長の条件へ到達した。
分割認識や本文選択による改善は未測定である。既知9列だけで採用せず、以下を追加する。
原画像/全真値/生成条件と選択ルールを固定するまで、候補chunkの追加NNを行わない。
候補の容量/group/confidence/空白の条件を新しい認識結果へ合わせない。

## 追加実スキャン

- 同じNDL PID1884801のコマ6/7/8を対象とする。公開manifestのPDM表示を継承し、全原JPEGの
  URL/取得日時/SHAと寸法を保存する。前の3コマに続く固定範囲で、認識結果による選択をしない。
- 各コマの先に読む本文ページ（右ページ）の最初の本文3列を使う。原画像で列境界を確認し、
  全本文が入り、隣の列/柱/ノンブルを避けるcropをNN前に固定する。元RGBを切り抜くだけとする。
- 本文GTは物理列順（右→左）、列間LF1個、最終LFなし。ルビは画像に残し、本文GTから除くという
  前段の規約を維持する。旧字・くの字点も同じコードポイント規約で、全9列を画像と照合する。
- 先行と同じ3モデル×eval/defaultのAPI、既定CLI DEIM/bandsを取得し、全24ページ本文組を保つ。
  取得した全検出領域を保存する。予想どおり3列にならない場合も画像や出力を除外せず、
  その差を記録し、全文の真値で比較する。本文/矩形の対応を原画像で確認してから列比較を行う。

同じ書式・書体の開発対照であり、モデル学習との重複は不明。未知書式のholdoutとはしない。

## 本文のない余白

同じ3コマの原画像から各2個、計6個の余白を使う。固定座標は
[220,480,280,2440) と [3300,480,3360,2440)。認識前に目視して表側本文がないことを確認する。
想定外の本文が入っていれば空GTへ合わせて隠さず、事前条件の不成立として記録する。
紙の汚れ/裏写りも原RGBへ残す。pixelの漂白や除去をNNへ加えない。

## 人工図形の出力安定性

3紙色×3図形×2密度=18条件を固定する。文字列を描画しない。

- 回転後の設計canvasは高さ50、幅44*N+20、Nは45/60。紙色はwhite=[255,255,255]、
  warm=[240,220,170]、gray=[225,225,225]。黒い図形をN個、x=10+44*k、y=9..40へ描く。
- barsは各box内のx=7..24を全32行塗る。zigzagは行j=0..31でx=min(j,31-j)+d、d=0..2を塗る。
  brushは32×32内の各pixelを独立の確率1/2で塗る。重なりはなくcanvas外へ出さない。
- brushの乱数seedは文字列 `vertical-capacity-noise-v1/{paper}/{pattern}/{N}` のSHA256の
  先頭8byteをbig endian整数として使う。Pythonの版と生成source、全点集合/SHAを保存する。
- 設計canvasを無補間の時計回り90度で元の縦長ROIへ戻す。製品側の反時計回り回転が、設計した
  RGBとbyte一致することを独立に検査する。入力はlossless PNG/RGB、JPEG変種を後足ししない。

反復bar/zigzagは記号や字形にも見える。空GTは診断上の規約であり、意味が一意な非文字正解とは
主張しない。ここでは候補が元の出力を変更しないことを安定性の採用条件とし、GTだけで
意味的な誤認識率を主張しない。原結果も空とは仮定せず、そのまま全件保存する。

## 行認識と採用判定

- 実検出列/余白/人工図形は全3モデルの元結果を先に揃える。既存capture_line_matrixを使う場合、
  8経路とそのうちraw_sessionを区別し、fragment_horizontal_batchは方向対照と明記する。
- 全RGB/GTと数値条件、Rust selectorを固定し、候補なしの全件も保存する。splitの認識へは元の
  回転RGBを使い、support maskを渡さない。選択は原結果と画像の条件だけで決め、真値を渡さない。
- 対照を絞って見かけの改善率を作らず、旧9列・追加実資料・余白・図形と既存ページ/縦横回帰を
  入力別none/width/strictの文字/単語距離で比較する。退行や安定性違反があれば採用しない。
- 追加実資料で少なくとも未観測だった元RGBへの適用を確認する。条件/方向/モデル/重複を
  独立標本と数えず、NN forward・API呼出し・製品replay・幾何検査を分けて記録する。

この仕様時点では追加3コマの本文転記、人工図形描画、候補chunk認識は未実施である。
