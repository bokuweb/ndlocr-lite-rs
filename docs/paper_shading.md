# 明るい紙の緩い陰影と行検出

公式upstream固定画像（出典とhashはtests/fixtures/paper_shading/source.json）では、
既定220の行検出が紙の左端の影をインクと数え、本文の先頭4行を結合する。
原画像・初回推論前に固定した手動原文は変更しない。公開画像の学習重複は不明。

先行するRedは、5つの本文領域をそれぞれの高さで検出すること。
合成の緩い二次元陰影では、1pxの細線・句読点・縦線も暗いまま保持し、
背景だけを明るくする。白紙上の文字、色パネル、急な境界を持つ灰色図形、
密な写真状の画像、不正寸法を負例にする。

前処理は専用のopt-in APIから開始する。局所的な明るい無彩色画素の分布で
紙面の背景を推定し、十分な紙の面積と緩い背景変化を確認する。
座標・寸法・モデル・認識文字列の置換は変更しない。通常の白い紙や対象外画像は
借用のまま返す。検出と認識へ同じ準備画素を渡す。

未知の写真と紙面の完全な識別は保証できない。独立資料・既存全文の検証が
済むまで既定経路へ組み込まない。薄い文字と背景の明度がほぼ同じ場合も未解決。
この1枚に合わせた閾値探索や原文の修正で精度改善を主張しない。

## 実装と開発画像の結果

局所タイルの明るい無彩色画素が75%以上ある場合に背景を推定する。
全体の支持率・陰影面積・隣接タイルの色差を確認し、急な境界は拒否する。
背景色はRGB各成分の中央値と明度の90 percentileから求め、同明度の色付き注記も
背景との差を明暗の両方向で残す。細い縦画線が占める最大2列だけは左右の背景一致で補う。
補正された領域はコントラストを強めたグレースケールになる。

同一の固定モデル・charset・220閾値・横書き分割で、原画像は56/68編集・2帯、
最終候補は18/68編集・5帯。Unicodeスカラーの空白・句読点・改行も数える。
先行Redで定めた開発ゲートは28編集以下と5帯であり、完全一致や本番受入基準ではない。
負方向だけの色差を使った19編集の候補も、紙より明るい色文字を消すため修正。
一度16編集になった灰度だけの候補は、同明度の色付き注記を消す回帰があり棄却した。
数字・句読点・「硯」などの誤読は残る。速度差は測定していない。
