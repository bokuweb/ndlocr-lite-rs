# 過去のページ単語距離退行の再監査

## 先行仕様

- 基準は `1a66fce`。`page-band-fallback` の単語距離退行12指標
  （3画像・6画像設定組）を、最新の実モデルで再確認する。
- 入力と正解は過去のmanifestのSHA-256に一致させる。正解の再描画・編集はしない。
- 既存の `record_missing_context_runtime_matrix` をそのまま利用し、
  `missing-line-context` の287画像全体を30/100モデル・評価/既定設定で実行する。
  実行前に実バイナリ・driver・全production source・model・charset・入力をハッシュで固定する。
- ページ本文は公開PageRecognizerの行をLFで接続したものとする。
  画像ごとの本文・矩形・confidenceと既存context traceを保存する。
- `tools/eval_ocr_metrics.py` のnone/width/strictで文字距離と単語距離を比較する。
  当時のbefore/after、直近ページ評価と最新実行を区別する。
  改善、同点変更、非変更、退行を別々に数え、合計で退行を相殺しない。
- 退行が残る場合は入力/crop/生モデル/構造処理を分離して原因を特定する。
  製品変更の前に追加仕様と失敗する回帰テストを固定し、小さいRed→Greenで進める。
  文書固有の語句補正はcoreに追加しない。
- これは既知の開発回帰の再監査であり、未知の実資料への一般化や性能改善は主張しない。

## 短い末尾断片の局所再確認（実装前の採用候補）

太字画像の100文字モデルでは、`作業が終わった` と `ら、` が別区間となり、
後者の生出力が `5.`（confidence約.902）になる。両区間の元RGBをまとめると、
前半を維持した `作業が終わったら、`（約.999）を得た。
丸字体30モデルの空白は区間内部の生出力であり、この施策の対象外とする。

- 対象はoverwide帯の既存安全分割が成功し、全区間のconfidenceが.9以上の経路だけ。
- 直前とは字形間分割（space_before=false）、直後は既存単語空白または行末で、
  現区間幅が高さの2倍以下・出力1〜2文字・confidenceが.95未満の場合だけ調べる。
- 直前は高さの3倍以上、confidence .98以上の区間を要求する。
  2区間は元座標で隣接し、結合RGBが実モデル入力比率内に収まることを要求する。
- 同じ供給モデルに結合した元RGBをHorizontalで再入力する。新規文字の推測置換はしない。
  失敗時、非有限/範囲外confidence、.98未満、元2区間の文字数加重confidence以下、
  前半本文の不一致、2区間の生本文の総文字数変化、末尾への空白追加、本文不変の候補では元結果を保持する。
- 採用時はモデル候補の末尾をそのまま選び、従来の結合空白判定を使う。
  対になる2区間のconfidenceを同じ結合候補confidenceとする。
  重なる組を連続採用しない。生API・単行API・他の復旧経路は維持する。
- まず局所失敗テストを追加し、制限/エラー/モデル容量境界と元RGB保持を検証する。
  公開API287画像×4設定とCLI287画像×2設定を画像別・3正規化の文字/単語指標で比較し、
  いずれかの退行があれば採用せず、失敗仮説を記録する。

## 生出力内の空白の余白感度（診断のみ、認識前に固定）

丸字体2画像の空白を含む既存区間RGBに、左右/上下それぞれ0・1・2pxの
純白余白を対称に加えた9条件を作る。2区間×9条件×30/50/100モデルを、
既存candidate exporterでHorizontal認識し、生本文・上位2候補とRGBを保存する。
元の画素を変更せず、区間の正解は先行の描画真値から該当区間を固定する。
元の画像外枠・分割手順や製品出力は変更しない。
これは既知2区間の診断であり、信頼度選択や自動余白付加の製品採用を意味しない。

## 検証結果

局所の未実装Red、公開APIの誤読Redを先に確認し、最小実装後にGreen。
287画像×6経路×3正規化の5,166文字指標・単語指標は全件非悪化。
変更は1画像の100文字モデル2設定だけで、生文字距離4→1、単語距離2→1。
完全一致の回復ではなく、丸字体の空白2画像と太字画像の別の挿入誤りは残る。
旧ページ評価と最新基準の1,722本文組もすべて同一と確認した。

通常619件、ONNX CI対象523件、example18件が成功。詳細・棄却した余白選択・
実行時sourceとbinaryのSHA・再採点手順は `docs/benchmarks/page-word-reaudit/`。
今回のページ行列はprimary30/100を対象とし、primary50・未知実資料・追加推論の速度は未評価。
