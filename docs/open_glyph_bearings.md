# 低密度で全高の字形にある左右余白

## 仕様（実装前）

Rust紹介文に残る `く ラ`・`する こと`・`た ド` は、文字そのものの左右余白を
単語空白と誤判定している。特に短い和文行ではインク幅の中央値28px（行高47px）が
字送り幅を過小評価する。低密度の全高字形に限って、行高を字送りの上限推定に用いる。

代表インク幅が行高の3/5（整数切捨て）以上の行で、字形幅が半行高以上1行高以下、
縦extentが2/3行高以上、最大列インクが半行高未満のとき、
左右余白を `(行高 - 字幅)/2` の切上げで推定する。
既存の細い字形・小書き仮名の余白推定と併用し、認識文字は置換しない。
細い括弧・縦画・背の低い小字形・極端に広い字形・Latin相当の狭い行は
追加対象にしない。広い実空白は保持する。

原寸3行の空白属性・固定モデル本文をRedで固定し、形状境界、実空白、
拡大/移動/反転と全画素被覆を検証する。既存全文と領域corpusをすべて比較し、
回帰した試行は採用しない。新しい和英混在文書も推論前に全文正解を固定して比較する。
これらは選択・調整に使った時点で開発データになる。

## 回帰を受けて追加する境界（実装前）

英字 `accuracy test` の `y` も全高で疎な字形に該当したため、
行内インク列群の1/3以上が2/3行高以上の幅を持つ場合に追加推定を限定する。
幅の中央値だけでは英字行と短い和文行を区別できない。
また、スキャン句読点後の34px/44pxの間隔を変更しないため、
前後両方の字形が半行高以上の幅と2/3行高以上の縦extentを持つ場合に限定する。
白列幅だけの上限は和文段落の精度を落としたため採用しない。
既存の小字形/細い字形の判定は維持する。英字実空白とスキャン句読点の
原画像・固定PARSeqを追加Redとして固定し、全文corpusで再比較する。


## 結果

固定モデルの3行と、英字実空白・スキャン句読点の負例をすべて通過。
Rust紹介文は8→5/357（2.24%→1.40%）。omoの全文/領域比較で入札142/836・106/863、
金融75/473、領域6/588・0/117・9/91、色ヘッダー2/17を維持した。
推論前に全文正解を固定した和英混在文書も40/326を維持。
調整に使った開発データの結果であり、未知文書への一般化は別途評価する。
モデル・文字集合・推論回数は変更なし。速度は未計測。
