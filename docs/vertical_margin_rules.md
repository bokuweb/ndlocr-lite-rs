# 縦書き段間の余白罫線

## 先行仕様

上下二段の複数列本文から十分離れた外側余白に細い縦罫線があると、
全幅の白帯がなくなる。段判定は初回検出した本文列の水平包絡内で行い、
元画像の検出・切り出し画素は変更しない。

- 左右いずれの外側余白の細線も、本文の段分けを妨げない。
- 段は上から下、各段は右から左、矩形は元座標。本文画素をすべて被覆する。
- 初回本文列の包絡内に段をまたぐ列があれば分割しない。
- 単列の段、幅広い罫線、本文内の罫線、横罫線・ルビは今回の対応を保証しない。
- 公式本文47列/1044文字の35編集以下、短列4/83、長列0/194、別書体0/124を維持。
- 開発画像への合成罫線であり、独立した実罫線資料の精度やproduction readyを主張しない。

幾何のRedを先行し、位置・拡大・左右を変えるPBTと既存の連続列対照を使う。
公式本文へ余白だけを拡張して細線を追加するモデル回帰も、期待を固定してから推論する。
