# 元領域を保持する行結合候補（opt-in）

## 実装前の仕様

幾何だけでは非連結字形1行と横線2行を区別できない。既存の行検出・認識・補正を
変更せず、呼出側が比較採点できる隣接2帯の矩形候補だけを列挙するAPIを追加する。
原文・認識文字・信頼度・モデルは入力にしない。候補の存在を採用判断にしない。

- 入力はページの正の幅/高さと、上から順に並び、上下に重ならない半開矩形の帯。
  空集合/1帯は許可する。逆転/空/画像外矩形、順序違反、画像面積のoverflowはエラー。
- `max_source_bands` を超える入力は走査や候補確保前に拒否する。
- 元の帯は不変の借用とし、各候補は元の隣接2帯の添字とその矩形和集合を持つ。
  候補を再結合しない。候補同士は元の帯を共有でき、同時採用可能とは限らない。
- 出力順は元の帯順。`max_candidates` と `max_total_pixels`（和集合面積の合計）を守る。
  残予算に入らない候補を飛ばし、後続の小さい候補は列挙できる。上限ゼロは無効化。
  未出力の隣接ペア数と出力総画素量を返し、予算不足と候補不存在を区別する。
- 入力長を超える事前確保をしない。整数演算を検証し、候補確保失敗はエラーで返す。
  計算量は入力帯数に線形、候補メモリは出力件数に比例。画像確保/推論はしない。

固定例と境界/PBTで原領域・添字・被覆・予算・決定性を検証する。
既存mixed_height画像では4帯を保持し、最後の2帯の和集合を候補として取得できること。
横線2行の反例も原領域を保つ。認識精度/速度の向上、採点器、既定経路への接続は
このAPIの受入条件に含めず、後続の独立資料評価で別途検証する。
