# P2: 実Page cropで失われた原インクの診断

## 実装前の固定仕様

P0のBBox部分交差だけでは、枠外が白画素か実際の画線かを区別できない。
P1は144既知入力の実Page cropを保存中であり、Oの旧Page比較は実行物の取り違えにより撤回済みである。
freshな444入力の無回帰gateを優先し、この独立診断では追加NN・製品変更・閾値調整を行わない。

- P1全864ケース、144入力を除外せず扱う。各元glyph BBoxの全画素を調べ、
  Pageの最初の全cropのunionに含まれるインクと含まれないインクを数える。
- 閾値は既存幾何と同じ平均RGB<220、およびアンチエイリアスを含む平均RGB<255の2種類を明示する。
  結果を見て閾値を選び直さない。重なるcropの画素は二重に数えない。
- 白領域だけが切れたBBox、1画素以上のインク損失、全インクを失ったglyph、注釈Noneの空白を区別する。
  画線を失ったglyphをGTから落としたり、無損失とみなして分割安全を主張しない。
- 小さいRGB例、四辺の切断、重複crop、境界値254/220/219、None空白と全白glyphをRed/Greenで固定する。
  小さな全矩形組を独立した画素座標集合oracleと比較する。
- 元PNG/GT/bboxのSHAとP1の実入力画素照合結果へ結合し、知見を仕様へ追記する。
  実インク損失があっても、それだけで誤認の因果関係や拡張方針の安全性は証明しない。

将来の検出枠完結策は、別の事前仕様と未測定の新規対照を必要とする。
