# 低密度の縦画でつながる短い行断片を保持する

金融文書の中央の「記」は300dpiで44px高だが、行投影のseedを満たすのは
上下の一部分だけだった。右側の「己」の細い縦画が途中をつないでいるのに、
10px/17px高の2行として認識され、`二二\n11` を返していた。
元画像・正解は `tests/fixtures/fragmented_glyphs/` に固定する。

通常行の中央値を文字高の目安にし、両方が短く、結合すると通常の文字高に
収まり、幅が文字高の3倍以下で横に重なる隣接断片だけを候補にする。
候補をつなぐ8近傍成分が文字相当の高さ・幅・密度を満たすことも必須とする。
空白を挟む別行、細い罫線、塗り潰し矩形、遠い断片は結合しない。
結合は2断片に限定し、連鎖的な結合で別行へ広げない。
行投影で欠けた外端の数画素は文字高の1/16の余白で保持する。
横書きとして検出した結合領域は、高さ/幅が0.8以下になるよう左右の背景余白を
均等に含める。公式PARSeqは正方形に近い入力を縦書きと見て回転するため、
余白なしの単独漢字を横書きのまま渡す必要がある。PARSeq自体の回転条件は変えない。

まず原寸「記」の分断と合成した境界条件をRedにする。
naive/fast一致、平行移動、実PARSeqでの「記」、既存の全文/領域CERを確認する。
語彙や文書固有の置換を行わない。修正に使った金融文書は以後開発評価と明記する。

## 評価結果

元の金融文書全文は473文字を初回推論前に固定し、変更前82誤り（17.34%）、
変更後77誤り（16.28%）。中央の `二二\n11` が `記` となった5誤り減少。
この原因を選んで修正したため、文書は以後開発データであり独立汎化の証明ではない。
既存の入札文書は146/836・108/863、領域corpusは6/588・0/117・9/91、
色ヘッダー2/17を維持する。空白・全角・モデル誤認識は正解から除外しない。
全文の原画像・固定正解・旧出力・新出力はomo PR #79で管理する。
