# 句読点空白候補Dへの、大きな独立点の追加対照

## 測定結果

新360件の1,440 ROI×3モデルは全て単一区間で正常終了した。
既存を含む1,718件・15,462文字/単語比較は退行0。新360件×3モデルでの選択変更は0で、追加改善とも数えない。
幾何支持は672本文組にあり、そのうち360本文組の真値は実空白を持つが、全候補条件では採用されなかった。
任意の大きな点への不変性の証明ではなく、後続の横縮尺対照でDを棄却した。

## 追加認識前仕様

Dの1,358入力の診断は非悪化で、製品接続の全単行/ページ比較は実行中。
まだ採用済みとは扱わない。既存collectorは高さの半分以上のareaを持つ成分を残すため、
本文から離れた大きな点が白列を分断する境界を新しく検査する。
Dの条件、1,358入力の真値/候補/結果、接続実装は変更しない。

- 新しい文は `審査内容、公開先` と `点検時期。対応方法`。
  句読点の直後にASCII空白0/1/2個を置く。
- 既存3字体（丸/角ゴシック/明朝）の24/40px。必要な非空白文字のmaskが未収録文字と
  異なることと空白の送り幅が正であることを確認し、font/Pillow SHAを固定する。
- 描画bbox周囲2px、上下各12pxの追加白紙を保つ。
  点のxは元描画の最大内部白列群の中央、同幅は左、なければwidth/2とする。
  文脈は無点、上端4×4、上下端各4×4、上端6×6、上端8×2の5種類。
  黒い矩形は画像内に収め、上端はy=0、下端はheight-矩形高。
  字形本体とは白紙で分離し、本文と真値を変更しない。
- PNG/JPEG75を保存後にdecodeした元RGBを固定する。
  2文×3空白形式×3字体×2サイズ×5文脈×2形式=360入力。
  原RGBと左右各2px/上下各0・1・2pxの候補で計1,440区間を用意する。
- 各区間の元画素/追加純白とSHAを検査し、固定した同じraw exporterで3モデルを認識する。
  全区間各1chunkを要求する。Dと同じ凍結Rust geometry/boundary probeと選択条件を使う。
  新対照の結果を見て条件や真値を変更しない。
- 既存1,358件をSHAで再利用し、計1,718入力×3モデル×3正規化の15,462文字/単語比較を
  公式scorerで検査する。追加対照だけでも1件退行すればDの製品採用を棄却する。
  全経路の接続検証が通っても、この退行を合計改善で相殺しない。

本文内の点、字形へ接続した汚れ、任意のスキャン汚損の不変性は主張しない。
必要なら後続案を別仕様・別対照で検証する。
