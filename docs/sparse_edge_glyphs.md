# 薄い行端字形の保持

列密度による左右の刈込は「二」「へ」のように各列の黒画素が少ない字形を
丸ごと消すことがある。通常行の高さを基準に、近接した独立インク列群のうち
文字幅・高さ・密度・位置を満たすものを元画像から回収する。

- 従来の細い横棒の回収と元のbboxを保持する。
- 追加対象は幅が行高の2/3〜3/2、高さが1/4〜4/5の疎な字形。
- 行中央に位置し、各列のインクは行高の1/6以下、面積は幅の2倍以上、
  bbox密度25%以下。本文からの空白は行高の3/2以内。
- 最大探索距離は行高の2倍。離れた余白ノイズ、細線、密なブロックを除く。
- 左右対称、naive/fast一致、元bboxの包含を検証する。
- 文書固有の文字置換、認識本文の正規化は行わない。

元PDFの未調整2ページ目を推論前に目視照合して固定した。863文字の初回誤り146。
同じ文書の別ページなので独立文書の一般化評価ではなく、修正に使う時点で開発データとなる。

## 検証結果

- 通常169件、実推論を含むONNX対象93件が成功。
- naive/fast一致、左右反転、平行移動24ケース、近接矩形・小点・幅広線・遠方字形を検証。
- omoの全文評価でページ2は146→143/863。消えていた二3箇所を復元。
  「へ」は画素を保持するがモデルの「ヘ」誤認識が残り、正解を正規化しない。
- 既存ページ1も153→151/836。描画6/588、実スキャン0/117、別文書領域9/91を維持。
- モデル変更・再学習・文書固有置換は行っていない。未調整の別文書は引き続き必要。
