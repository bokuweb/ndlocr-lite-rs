# 追加実資料traceの公開再検算

完了した観測のJSON/log/argv/事前binding/source/build receiptと全RGB memberを公開する。
同じcropを多数含む出力ZIPはmember単位で内容address化し、元ZIPのSHA/bytesと全member一覧を記録する。
公開packetが保証するのは各member byteであり、ZIP containerのbyte再現ではない。元ZIPは私有実験記録にも保持する。
既存公開controlsとFVB baseline packetも認証し、全36対応、174 RGB、396 CSV行、O棄却理由を
モデルなしで再検算するreaderを未実装Redから作る。公開前後で新たなNNは呼ばない。
