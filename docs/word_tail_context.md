# 実空白の後に残る短い語のモデル文脈を保持する

Rust紹介文の見出し411×36pxは行全体では256×24モデルの比率を超える。
番号の後の実空白で分割した残り363pxは入力に収まるが、従来の固定比率8で
さらに分割され「パフオ」/「ーマンス」になっていた。同じモデルへ残り全体を
渡すと「パフォーマンス」を認識する。認識後の置換は行わない。

仕様: 従来の安全な白列による分割を行い、最後の実空白境界の後に複数区間が
残る場合のみ、その末尾全体が実モデルの入力比率と20未満のインク列群に
収まれば一つにする。先頭の空白属性は維持する。実空白境界がない行、
末尾が入力比率を超える行、密集字形は従来分割を維持する。
全体の画素被覆・字形数上限・モデル寸法の検証を維持し、寸法境界・移動PBT・
実crop・固定モデルのRedを先に追加する。omoの全文・領域corpusで回帰を確認する。

## 検証結果

原寸の区間数・固定PARSeqの期待値はいずれも旧版でRed、修正後にGreen。
モデル比率の等号境界、字形数20/21、単語境界なし、拡大/平行移動24ケースを検証。
原画像の空白は27..70で、拡大後の中点は `27*scale + (43*scale)/2` となる。
整数丸め後の座標を単純に拡大した期待値とは異なるため、白列範囲から期待値を計算する。

omoの開発corpusはRust紹介文11→9/357（3.08%→2.52%）、
入札1ページ目145→144/836（17.34%→17.22%）。
「パフオーマンス」→「パフォーマンス」、「リメモリ」→「りメモリ」が改善した。
「よ り」の空白は残る。入札2ページ目106/863・金融75/473・領域6/588・0/117・
9/91・色ヘッダー2/17は維持した。認識後の置換・追加推論はなく、モデルも維持。
