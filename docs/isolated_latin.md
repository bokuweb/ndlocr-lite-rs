# 小文字高の孤立行を保持する

和英混在ページで、行の文字高41pxに対して小文字の本体が20〜22pxしかなく、
行投影のseedにも既存の全高字形seedにも届かず `i / w / m / a` が欠落する。
文字列の置換ではなく、未検出の画素成分をモデルへ渡すことで改善する。

既存の全高seedと断片結合の条件は変更しない。孤立行の補助検出に限り、
文字高の2/5以上・3/4未満の成分を、通常の横書き行（幅が文字高の3倍以上）の左端から
文字高の1/4以内にある場合に認める。縦横比・面積・密度で小点、細線、塗り潰しを除き、
ギャップ境界に触れる成分を除く。上部の点と同じ基線の近接成分だけを既存規則で含める。
原寸cropと移動に対して全字形の画素被覆、naive/fastの一致を保証する。
本文の左端から離れた小さい図形、密な矩形、点は昇格させない。
幾何条件だけで字形と図形の完全な区別はできないため、別文書でも回帰評価する。

fixtureはomoのword_text_sample.pdf page1を300dpi描画した開発データ。
この文書で選んだ改善を未知文書への一般化とは主張しない。

小文字本体だけを高さ一杯に拡大しないよう、復元行は基線側を固定して周囲の文字高+2pxまで
上側の余白を含める。横書き行なので、幅も高さの5/4以上まで中央の余白を含め、
PARSeqの縦書き自動回転を避ける。画像端や前の行を越えては拡張しない。
原寸の固定モデルでは検出直後の `i / w / m / a` が `1 / W / m / 3`。
余白でw/m/aの改善を試験する。i/lは余白の比較でも数字への誤読が残り、
正解文字への置換は行わない。iまで完全一致する当初の実験的期待は達成していない。
