# 行末から右下へ離れた句読点

Phase 5の回帰改善。紙の陰影補正を適用した公式横書き手書き画像には、
行投影から落ちた句読点が残っている。原画像、原文、220の閾値、モデルは維持する。
初回の追加推論前に目視と画素で固定した半開範囲は以下。

| 行 | 記号 | 画素範囲 |
|---|---|---|
| 1 | 、 | [434,57,439,64] |
| 2 | 、 | [547,142,552,150] |
| 3 | 、 | [555,245,560,254] |
| 4 | 、 | [570,335,575,342] |
| 5 | 。 | [615,434,624,445] |

Redは、5つの本文帯が各記号の画素を含み、帯の数を増やさないこと。
独立した合成画像では、長い本文の右下へ離れた疎な小成分を含める。
塗り潰し、小点、罫線、上側の点、遠い点、短い字形だけの行、次行の成分は
回収しない。拡大・移動後も同じ契約とnaive/fastの一致を確認する。
行末が疎な余白ノイズだけで広がった場合、その境界を本文の足場にしない。

行高・行末との距離と成分の寸法・密度で候補を限定する。元の本文帯を基準に
一度だけ選び、回収した成分を足場に探索を連鎖しない。隣接行を跨がず、
画像外へ広げず、元の帯を縮めない。文字列置換や辞書補正は行わない。

実モデルの追加ゲートは、固定原文68文字の厳密編集距離を18未満にし、
最終行に「。」を認識すること。座標の回収だけでは認識改善とみなさない。
既存の全文・座標回帰を確認してから公開依存へ反映する。
点ノイズと句読点の完全識別や未知画像での汎化は保証しない。

## 開発画像での結果

最初の候補は18→10/68編集になったが、本文のない右余白の小成分も回収した。
合成の余白ノイズを追加してRedを確認し、元の行末一文字高の範囲で
高さの半分以上に2画素以上の筆画がある場合だけ、右側の成分を認める。
既存帯の下端を跨いでいた成分は、元の帯と連結した範囲として回収する。
疎な小成分だけを扱い、クリップ端に触れる成分は使わない。

修正後は7/68編集・5帯となり、5行とも句読点と最終「。」を認識した。
「硯にむかひて」などの誤読や余計な空白・先頭の読点は残る。
先行ゲート（18未満・最終句点）を満たす開発データの結果であり、
未知資料の精度や本番受入を保証するものではない。追加のモデル推論はない。
速度は未計測。紙の陰影補正は引き続きopt-inである。

## 遠い余白のノイズからの独立性

句読点の候補は元の帯の左端から右端の一文字高先までに限られる。
この範囲から離れた余白の点ノイズで、成分数の打切り上限に達し、本文の
句読点まで失われてはならない。本文と句点を固定し、右の遠い余白へ260個の
独立した点を加えても、naive/fastとも元の句点を含む同じ帯を返すことをRedにする。

成分走査は元の帯の左端の1画素手前から、許容される句読点の開始位置に
最大成分幅と1画素を加えた右端までに限定する。探索境界で切れた成分は
句読点として使わない。既存の全幅成分走査と256成分の上限は他の経路では維持し、
近傍自身が過密な場合も上限を緩和しない。一般的な精度・実時間の改善は別途評価する。

修正前は260個の遠方ノイズで `[18,19,185,64]` の帯が `[18,19,162,53]`
へ縮み、句点を除外した。修正後は拡大・移動と257〜280個のノイズを
組み合わせた24ケースも元の句点境界を維持した。幅1200画素の合成例では、
この成分走査だけの範囲が50,400→8,274画素となる。全ページの行投影や
モデル推論は別途必要であり、この比率をOCR全体の速度改善率とはみなさない。
固定モデルの手書き結果は7/68編集・5帯のまま維持した。
