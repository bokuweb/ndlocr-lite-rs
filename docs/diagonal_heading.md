# 短い見出しの斜め画を保持する

和英混在ページの「ノーマル」は行投影で[368,661,524,688]に切られるが、
「ノ」の連結成分は[360,660,385,691]にあり、左・上・下の画を欠落させていた。
固定PARSeqは切れたcropを高いconfidenceで「ルマーノ」と逆順に誤認する。
行の整列や文字の置換では修正せず、元画素から連結成分を復元する。

既存の短い行の上下復元を、通常字高の6倍以内の行へ拡張する。
周囲の行から得た字高に対して3/4未満の低いbandだけを対象にし、
左右への許容差は字高の1/4までとする。成分の高さ・幅・面積・密度、
既存bandとの交差、前後行への非接触、復元後の高さ上限は維持する。
新たな空白を一律に足さず、元の字形がband外へ続く場合だけ回収する。
幅と左右差の等号境界、ノイズ、隣行、原寸画像の移動とnaive/fast一致を検証する。

原寸fixtureはomo word_text_sample.pdf page1（300dpi）の開発データ。
固定モデルで「ノーマル」を期待するRedを先に固定し、全文の厳密Unicode編集距離と
別文書の既存corpusを再評価する。未知文書の一般化や速度改善は主張しない。
