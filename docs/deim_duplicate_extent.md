# DEIMの重複行と別様式の回帰評価

## 評価前仕様（2026-10-18）

PR #22 の固定神戸市資料で、既定CLIは「また、変更作業に伴う影響として」で始まる
物理1行を異なる認識文字列で二重出力する。文字列一致による削除では解消しない。
まず生DEIM検出・選択後cropの座標/クラス/信頼度を凍結し、既存90% IoU条件と
同じクラスの保護を踏まえて、幾何に根拠がある同一行候補かを調べる。
原モデル・閾値・charset・生検出APIは変更しない。

修正前に仕様・実画像Red・合成境界/負例/PBTを固定する。候補が不確実なら保留し、
近接する別行・包含された短い行・異常座標を抑制しない。採用には物理行の一意性だけでなく
全文none/width/strict距離の改善、各入力の非悪化、既存の実モデル回帰を要求する。

別様式の初回対照は国立国会図書館2025-05-12の報道発表資料2ページ目。
出典: https://www.ndl.go.jp/file/news/fy2025/250512_01/pr250512_01.pdf
利用条件: https://www.ndl.go.jp/sitepolicy/terms （PDL1.0）。ロゴや第三者図版のない
2ページ目の本文を推論前に切り抜き、PDF抽出の真値を描画と照合してhashを固定する。
この資料に対する初回の出力を候補のパラメータ調整に使わず、対照として先に比較する。
初回観測後は開発データと明記する。holdout精度を一般的な保証にはしない。

## 生検出の観測と追加選択条件（実装前）

対象は同クラス `line_main` の3候補。強い行は[69,863,948,887] (0.9364)、
[43,902,563,925] (0.9413)、余分な領域は[44,862,947,925] (0.2848)。
後者は2行を覆うが1行として認識され、先頭行だけを二重出力する。
通常の近似同一矩形NMSを緩めず、その後に次の限定した画素付き選択を追加する。

- 既存のクラス競合選択結果を信頼度順に走査し、既に保持した検出だけを根拠にする。
- 正常な画像内矩形に限定する。同クラス/異クラスとも、候補の2倍より高い信頼度の
  横長（縦長）の行がちょうど2つあること。候補と各行の主方向は同じ。
- 各支持行は縦横比4以上、主方向長が候補の1/2以上、従方向長が候補の1/4〜1/2。
  各支持行の面積95%以上が候補内にあること。
- 支持2行は従方向で離れ、その間隔が小さい行高の1/4以上、大きい行高以下。
  2行の矩形和の外接矩形と候補のIoUが既存の90%以上条件を満たすこと。
- 候補内の全非白RGB画素が、支持2行それぞれを行高/12切り上げだけ広げた領域の
  和集合内にあること。全白の候補は抑制しない。独立した追加画線があれば元の候補を保持。
  このcollarはDEIMの画素座標の量子化差を許容するもので、支持cropの外側の
  全画素を新たに認識できる保証とはしない。モデル真値/本文は入力にしない。
- 元RGB・生検出・勝った2行の座標とmetadataは変更しない。出力は元の順序に戻す。
  不正RGBでは追加選択を行わず、既存の呼出側の検証へ渡す。
- 3経路（CLI crop/cascade/PageRecognizer）に同じ処理を使う。倍率・左右移動・
  縦横反転のPBTと、信頼度/重なり/余白/追加画線/少数支持の負例を追加する。

## Red / Green と全件比較

実DEIMの先行Redは対象2 crop→1 crop。生検出51件はJSONで前後同一、選択結果は
33→32件で、大矩形[44,862,947,925]だけを除去。他32件の座標/信頼度/文字数は同一。
合成/cascade/PBTの3 Red→Green。追加画線（254の近白を含む）、支持不足、弱い信頼度、
部分重複、異常座標、全白、距離境界、抑制候補の連鎖禁止を含む6件が成功。
実PageRecognizerも対象1行・全32行を保持する。

固定バイナリと公式モデル、debug/CPU intra thread=1で4画像×2設定×2版の16プロセスを
実行した。既定DEIM CLIの神戸市資料だけ本文が変わり、生111→75/1034字、width64→28字、
strict95→59字。別様式のNDL資料と既存2資料の本文はbyte同一。帯検出CLIの全4資料も
byte同一。none/width/strictの全24画像別指標は非悪化。モデル/閾値/charsetは不変。
通常479件・実モデル381件成功。fmt/diff、対象Clippy成功（変更箇所以外の既存17警告）。

出典と生本文、DEIM結果、各指標・実行条件は `docs/benchmarks/deim-extent/`。
未知資料への一般化、JPEG/低解像度、collar内の未検出文字の完全回復、速度改善は未確認。
次は認識後の括弧削除と改行をまたぐ文脈を分離する。全行一致や未知資料精度の保証はしない。
