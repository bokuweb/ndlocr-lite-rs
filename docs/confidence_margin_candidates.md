# 出力前に固定する原画像/縮小候補の比較

## 仮説と固定方針

既知6chunkの事後分析を条件調整に使わず、原chunkと縮小限定余白の2候補を平均信頼度だけで選ぶ。原画像を先に1回認識し、横幅が高さの5倍以上のchunkだけを `compact_horizontal_margins(height / 4)` へ渡す。縮小画像が元と同じなら追加推論しない。異なる場合だけ同じsession・方向で1回認識する。平均信頼度が厳密に高い候補を使い、同点は原画像。語彙/句読点/言語/解像度/資料別の例外や閾値は加えない。原/候補の本文・信頼度・寸法を両方保存する。入力不正・推論失敗・非有限/範囲外信頼度はエラーとし、採用結果に混ぜない。

libraryに明示opt-inの推論callback APIを追加する。通常pipelineは変更しない。製品pin d05d46c・製品code 29b934eのコピーを固定し、dev依存の公開library候補APIだけをtest moduleで接続する。原chunkのRGB/順序/寸法、行座標、既定の行分割/後処理/予算は共通にする。推論callbackの追加呼出しはアダプター内部だけで、既存のchunk予算を維持する。

## 新しい資料を先に指定

過去の統計局2資料とは別に、以下の**物理1ページ目だけ**を使う。OCR前にPDF全体・生成画像・PDF文字由来の正解をSHA256固定し、目視で照合する。いずれも日本銀行資料なので分野・レイアウトの多様性は限定的。学習重複は不明で、厳密な独立holdoutとは称しない。

- 日本語: https://www.boj.or.jp/mopo/mpmsche_minu/opinion_2026/opi260731.pdf
- 英語: https://www.boj.or.jp/en/mopo/mpmsche_minu/opinion_2026/opi260319.pdf

各ページは200dpi PNG・150dpi PNG・200dpi JPEG quality60/subsampling2の3条件（計6画像、独立資料は2件）。正解はpdfplumber dedupe_chars、x_tolerance=2/y_tolerance=3、末尾改行1個のみ除去。異なる読み順・日本語の空白も事後修正しない。画像の文字を見て正解抽出の欠陥があれば推論前に明記して固定する。

既存製品比較の8画像（統計局6変種+既知正読対照2件）も再評価する。元の532calls・本文・座標・信頼度を再現する。これは既知の回帰対照であり新資料とは区別する。

## 先行テストと採用ゲート

Redは原/縮小の両順の信頼度・同点・同一入力の追加推論抑止・縦長・不正RGB/overflow・失敗伝播・非有限/範囲外信頼度。小さい独立oracleのPBTで選択と呼出しを検査する。

全14画像の各文字誤り/行数誤りを非増加、新資料6画像の合計文字誤りを厳密減少、既知正読対照2件を完全一致維持、全元chunk/座標一致、全推論成功を要求する。正規化なしUnicode編集距離と公開tools/eval_ocr_metrics.pyの全28全文を照合する。ゲート失敗時はaccepted=false、終了1、本番pin/経路は維持する。成功しても別分野・ページ全体前景・release全変換速度/メモリの不足を明記する。

実行はCPU/1thread、順序は画像index偶奇で対照/候補を交互にする。追加モデル呼出し数と各推論/準備/ロード/全体時間を記録する。dev共有hostの単発値を本番速度改善とは扱わない。
