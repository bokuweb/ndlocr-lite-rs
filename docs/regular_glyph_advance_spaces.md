# 一定の字送りと連結空白

金融文書の凍結済み真値に対し、「開示いたしま した」「予定と しておりま した」の区間連結が余分な空白を追加している。元画像には単語空白がなく、各区間のモデル出力にも空白はない。字形の左右余白を単語空白と誤認している。

横書きの原画像から全幅・全高の独立した画線群を選び、隣接する字形中心の送り幅が行高付近で一定の場合だけ、その送り幅から左右余白を推定する。少なくとも6組の支持と、行全体に十分な全角相当字形が必要。対象の両隣も半行高以上の幅・2/3行高以上の高さを要求し、句読点・細い英字・小画・連結画線を除く。実空白は、字形中心距離が支持済み字送り＋行高/8を超える場合、または推定余白を引いても既存単語閾値を超える場合に残す。支持不足・不規則な送り・極端な字幅では既存判定を維持する。

変更するのは区間連結時の空白属性だけ。優先分割、原画素、モデル・文字集合は変えない。空白属性を参照する既存の尾部結合・白余白cropへの影響は全文回帰で確認する。今回の金融行では区間数・境界とモデル本文が変わらないことを固定モデルで検証する。文字列置換や辞書は使わない。既存Auto/Horizontal APIを維持し、追加推論を行わない。

合成Red、支持不足・章番号直後の実空白・句読点・英字・不規則送りの保護、整数倍拡大・移動・反転PBT、固定モデルの既存金融行で検証する。omoは凍結済み全文真値で公開版のRedを先に確認し、候補と公開依存で全回帰の本文・座標を比較する。全角/半角・モデルの字形誤読は対象外。未知資料の汎化と速度改善は別途検証が必要。

半角英字列との境界や半行高に届かない仮名は、一定の全角字送りだけでは実空白と区別できないため今回の補正対象にしない。金融の「30日 の」「テス ト」などは残課題とし、既存区間数・モデル本文と和英混在の実空白を保護する。
