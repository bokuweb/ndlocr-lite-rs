# 引用符の多い行で字幅の推定を保つ

句読点や引用符の細い連結成分が過半数を占める行では、全成分の幅の中央値が
英字本体より小さくなる。原寸の `test` 内の6pxの字間を単語空白と扱い、
分割・結合で `te st` / `t est` を生成する。

行高の1/3未満の細い成分が過半数、そのうち1/2未満の低い成分が全成分の1/3以上あり、
行高の1/3以上の幅・1/2以上の高さを持つ本体が
全成分の1/4以上ある場合だけ、本体幅の中央値を代表幅に使用する。
単語空白と判断した分割を字形内の狭い間隔へ置かず、広い実空白は維持する。
条件外の行、短い行の文脈保持、全画素の重複なし被覆は維持する。

英字相当の代表幅では、その半分未満の幅かつ半行高未満の低い字形の左右余白を
代表幅との差の半分として差し引く。引用符と直後の句読点の狭い余白を単語空白にしない。
全高の細い英字はこの条件から除き、広い実空白は余白を引いた後にも残す。

`jlsi/omo` の句読点評価PDFの22行・627文字は初回推論前に固定済み。
原寸cropと合成境界・拡大移動のプロパティをRedから始め、固定モデルで比較する。
文字列置換や引用符・dashのUnicode正規化は行わない。

固定モデルでの全文評価は105→100/627（16.75%→15.95%）。22行を維持する。
`omo` の `fixtures/expected/ocr_punctuation_space_accuracy/` に正解・SHA・本文・座標を保存する。
固定モデルの最終行は単語内・句読点直前の不要空白を解消するが、曲線引用符をASCII引用符と
読む誤りは残る。ライブラリの実モデルテストはこの既知のUnicode誤りも含む生出力の回帰であり、
原文の完全認識を意味しない。別箇所の悪化も厳密編集距離へ含め、差し引き5文字の改善である。
