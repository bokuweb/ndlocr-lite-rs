# 固定済み評価のモデル別実行

推論開始前に固定したevaluate.pyの採点条件・群・原画像・真値・候補条件は維持する。
モデル50/100の推論待ちの間に、完了したモデル30から同じ保存raw再生と正式scorerを実行する。
新しい選別・閾値調整ではなく実行順の変更である。

各モデルの全19,440条件、全群、none/width/strictを保存し、最後に3モデル分を統合する。
RGB実入力captureは実際に収集したmodel30の全画像を共通に照合する。
baselineは凍結B、candidateは凍結Cのbinaryを保持し、再生でNNを呼ばない。
採点CSV/MDは従来と同じscorer引数で作る。元の固定driverとモデル別driverの両方を保存する。
全モデル分が揃い、旧新全群の入力別文字/単語退行0と未重複RGBの実適用が確認できるまで製品へ接続しない。
