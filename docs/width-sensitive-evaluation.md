# 全角ASCIIの差に隠れる字形退行の検査

通常の `none` 編集距離を保持し、補助指標 `--normalize width` を追加する。
U+FF01〜U+FF5EだけをU+0021〜U+007Eへ写像する。改行・空白・大小文字・
片仮名・丸数字・合字・単位記号はそのまま。NFKCや文脈による置換はしない。

正解 `ＡＩ関連企` に対して `AI関連企` と `Al関連企` は `none` ではともに
2誤りだが、`width` では0と1になる。本文の補正ではなく採点専用である。
生の指標と併記し、どちらか一方の改善だけを本番採用の根拠にしない。
既存の既定値basic、none/basic/strictの処理は維持する。

Redは上記の反例、全94コードポイントの写像、対象外文字・空白・改行保持、
CLIからのCSV出力。標準ライブラリunittestで全OSのCIに追加する。
