# 比例幅行の単語空白

既存の混在書式行で `drawn using` と `New Roman` がchunk連結時に空白を失う。既存の独立書式行でも `BoldItalic to` / `bold italic` が欠落する。正解・モデルは変更せず、原寸とchunk別の出力で入力/連結/モデルのどこで欠落するかを分離する。

最初のRedは、原寸混在書式行の分割列520・986で実空白属性を要求する幾何回帰と、固定PARSeqの文字列回帰。分割位置と推論回数を維持し、実単語間隔の支持がある行だけを対象とする。閾値を広げる場合は合成境界/PBTと既存和文・句読点・英文・全文評価の回帰を確認する。文書固有の単語置換は導入しない。

## 判定条件の追加

- 従来の2倍分離・3空白以上の支持を維持する。6空白以上がまとまり、直前1個だけが中間幅で、その前の字間とは2倍以上離れる場合も二群とみなす。中間幅2個、支持5個以下、広がり2倍超は対象外。
- 斜体で字形が連結するとインク幅の中央値が全角相当になる。行高2倍以上の連結成分が3個以上ある場合のみ、全角相当中央値による分布推定の禁止を解除する。分割位置の選択は従来閾値を維持する。
- 日本語・句読点の左右bearing補正は維持する。全角行全般の閾値を下げない。

## 原寸・固定モデルの結果

- 公開b06c289では3テストともRed。混在書式は境界520/986の13列、斜体は878の15列/1214の11列で空白属性がfalseだった。
- 修正後は同じ分割位置・区間数（混在書式7、斜体5）で4空白を復元。混在書式の隣接区間1個は、既存の単語境界crop条件が成立して379列→366列になる。固定モデルのその区間の出力は同一。
- omoの凍結真値を変更せず、独立書式領域2/147→0/147、混在書式16/1032→14/1032。両画像は現在は開発データであり、未知文書への汎化の証拠とはしない。
- モデル・charset・推論回数を変更しない。前処理の小さい追加走査はあるが、この増分の速度は未計測。
- 公式upstream `d001dad2013ceabb5736ff8d637474e443eb73c2` を2026-10-17に再確認して更新なし。
