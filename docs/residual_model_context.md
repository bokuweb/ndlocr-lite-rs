# 区間内の括弧・空白のモデル誤読を分離する

## 先行仕様

固定 `chromatic_text_contrast/page.png` の4/9/16行目の括弧と、7/15行目の
`Italic', font` の空白を、既存の正規化・分割・固定PARSeqで再現する。
正解・モデル・charsetは変えず、chunk別の生出力と信頼度を記録する。
連結処理で作れない誤読は、入力画素とモデルの条件に分離する。

最初のRedは上記5箇所の完全な文字列を要求する。汎用的な画像条件で改善できる
根拠が得られるまで、推測に基づく文字置換や自動再推論を追加しない。
候補が得られた場合は合成例・境界条件から先行テストを追加し、既存コーパス全体と
独立資料の回帰を確認する。改善できなかった実験も証拠を残し、未解決として扱う。

## 小さい水平単語断片の回転を避ける仕様

初回Redで16行目は `Color [SlateBlu` と75x62の `e],` に分かれ、後者が
縦向き判定で回転され `19` になった。同じモデルで503x62へ結合すると完全一致。
単語境界/行端で挟まれた隣接2区間に限定し、内部境界に単語空白がなく、片方だけが
モデル前処理の回転条件（高さ*5 > 幅*4）を満たす場合だけ結合する。
結合後はモデル実入力の幅/高さ比以内かつ従来のインク列群上限未満とする。
元画素と最初の連結属性を維持し、推論を増やさない。十分な文脈・入力比・列群数・
単語境界がなければ従来の区間を保つ。合成の境界・反転/拡大PBT・固定モデルを先行する。

診断で7行目の `Italic', font` は区間2/3の境界に空白属性がなく、連結時の欠落と判明。
前回の「7/15行目とも区間内モデル誤読」という分類を訂正する。15行目は区間内欠落のまま。

合成3テスト（拡大/移動/反転PBTを含む）のRed→Greenを確認。
固定PARSeqの先行Redも、`Color [SlateBlue], background color Color [Orange]. The end.`
の全文一致へGreen化した。対象行は6→5区間で、追加推論なし。

omoの固定1032文字・163語では10→7文字編集、9→8単語編集。
別の描画28ケースは6→3/588文字編集で、明朝20pxの `100万円10 支払期限` が
`100万円、支払期限` へ戻った。他27ケースの本文は維持。既存の座標付き247行は
座標を維持し、変わった本文は混在書式の対象1行のみ。画像・モデル・charset・真値は維持。

## 2026-10-17: 追加診断

### 残る引用符・斜体括弧・区間内空白の診断

混在書式の固定評価には5文字編集が残る。正解・モデル・charsetは固定し、
引用符の置換/脱落、斜体括弧の誤認、コンマ後の空白脱落を別々に診断する。
文字列の置換は追加しない。

まず固定モデルへ渡す原寸区間とその認識を記録する。境界変更の候補は、
既存の字形を切らず、モデル入力比率と字形数上限、全画素被覆を保つこと。
空白欠落が区間内で起きる15行目（zero-based 14）について、短い語尾を確認済み単語空白へ
戻せるかを先行Redで確認する。引用符・括弧は周辺余白の感度も診断する。
変更の採用には全コーパスの回帰確認が必要であり、単一行の改善だけでは採用しない。

### 行頭の孤立した上部記号への最小余白

行頭の小さい引用符は元画像に残り、上下それぞれ2行の白余白で固定モデルの脱落が解消する。
単語境界に囲まれた水平区間に限定し、左端付近の8近傍成分が高さの半分未満・
幅の四分の一未満で上半分にあり、その下に別の画線がなく、右に本文がある場合だけ、
高さの1/32（切り上げ）の白余白を上下へ足す候補を試す。
全画素・水平境界・回転分類を維持する。通常文字の上部画線や i の点、単独記号、
単語内の切断には適用しない。合成Redと固定モデルRed、全コーパスを確認する。

行頭引用符の固定モデルRedと合成画素Redを確認し、最小余白でGreenにした。

omo側の固定ONNX・表構造化122テストで、混在書式は5→3/1032文字編集、
