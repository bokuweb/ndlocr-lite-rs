# 色パネル左右の補間色外縁

上下外縁と同様に、背景色と外側白紙の混合色が左右で暗い縦線へ変わり、本文行を結合することがある。背景として既に確認された色パネルに限って左右の外縁を検査する。

各行の外端の背景標本から外側へ最大3画素の同じ背景色/白の線形混合を追う。終端は4近傍でページ外周へつながる近白紙でなければならない。隣接行で境界位置の差が1以下、背景成分差が24未満の連続区間を64行以上確認した場合だけ補間部分を白にする。外周紙自体は元RGBを維持する。

成分249以下で途切れる外側紙、囲まれた白字形、黒や異色の縦線、3画素より厚い混合縁、短い混合縁、背景標本のない色文字には適用しない。前後で座標と画像寸法は維持する。近白字形が外側紙へ接する曖昧さ、JPEG、任意図版、性能/メモリ、独立holdoutは引き続き未解決。

先に左右の階段状外縁の失敗テストを追加し、内部字形・異色罫線・厚み・長さの負例と色/平行移動PBTを加える。固定28画像の比較では原文や行数期待を変更せず、旧結果を再現して全既存画像の非悪化と24負例の画素恒等を検査する。16行未達や強い精度条件の失敗はそのまま保存する。

これは左右の補間色除去の条件であり、既存の全高単色枠の背景延長を変更するものではない。一定色・全高の4画素帯は旧8f641bdでも背景化するため、この負例は行ごとに混合率を変えて別処理の影響を避ける。初回の負例と旧版での失敗は証拠に保持する。

### 外側の孤立色文字

実画像の診断で、列背景色に偶然近いパネル外の色文字を最初の背景画素として拾い、外縁追跡が途切れることを確認した。64画素以上横へ連続して背景一致する領域の端だけを起点とする。孤立色画素を間欠的に置く回帰を先に Red とした。元の列背景推定・色文字の変換規則は変更しない。
