# 接触と分離部品のnative適用対照を探す幾何screen

## 実装・描画前仕様

情事/事情の10,944画像は入力/真値/画素検査を通過したが、真値を仮rawとしたfc5→固定案の
増分適用は0だった。入力と結果を保持し、この時点では追加NNを行っていない。
支持条件は変更せず、適用対照を選ぶための小さな幾何screenを先行する。OCRの精度測定ではない。

- 対象の順序付きpairを `[情本,本情]`, `[情木,木情]`, `[情車,車情]`, `[情生,生情]` に固定する。
  既知の情部品と、接続した単純な本/木/車/生のglyphを組み合わせる。未知字形holdoutとは扱わない。
- 同じmincho font file・20px・palt=0/1、各本文の末尾に `」`、PNGだけの16画像をnative描画する。
  font file/glyph/advanceと元PNG/切り出しRGB/truth/SHAを保存し、RGBは描画後に編集しない。
- 真値を仮rawとして、凍結したfc5実製品処理と凍結済みtest-only案を比較する。
  幾何到達性/既存処理との差だけを記録し、モデルの予測/精度/改善数へ数えない。
  16入力は適用0も含めてすべて保持する。
- どちらかの語順で増分適用がある最初のpairを、列挙順で適用対照に選ぶ。
  これは幾何条件による既知部品の意図した選択で、未知のNN結果による入力選択ではない。
  選んだpairの追加NNの全組合せは、生成・認識前に別仕様で固定する。
- 全pairで0なら支持条件を変更せず停止し、次の検討を別仕様にする。
  このscreenと、元の10,944画像を、新しい独立した精度標本へ合算しない。
