# 全文領域のない行と、既存枠が覆わない画線の診断

## 診断前仕様

bae38d3は同じ行の信頼できる親枠があるときに断片の二重出力を整理した。
一方、混合A1のJPEGではDEIM=.3に全文枠がなく、断片だけでは行頭のAが欠ける。
全体/帯の同一モデル出力は前段ですでに記録済みなので、追加推論より先にその可能性と反例を調べる。
製品の条件・出力はこの診断で変更しない。

対象は前段の固定184画像（反復160＋帯復旧24）、30/100の2モデルと
PageRecognizerのeval/default、計736本文組。raw probeの全候補を調べ、最良の真値一致を選ぶ処理は作らない。
原画像と帯cropの全候補について、元のbbox/寸法/生text/現在の反復保持text/confidence、
native容量、全文画線被覆、既存出力枠の外にある220前景の画素数・列数・外接矩形を記録する。
画像・モデル・前段source・raw/visible JSON・API metadata・候補PNGのSHAを固定し、
原PNGのdecode RGBと元の評価入力のRGBが同じことを確認する。

画線の未被覆量は候補内の前景と既存bboxの和集合との差集合として数える。
bboxは半開区間で、画像外はclipし、重なり・重複bboxで二重計上しない。
元画素の色は変更しない。閾値は前段と同じRGB合計660未満。
これはノイズを含む記述量であり、1画素でも外にあれば復旧すべきとは解釈しない。

none/width/strictの文字/単語距離は既存 `tools/eval_ocr_metrics.py` の正規化・距離関数を使う。
全文画線を含む候補だけを全文truthと比較し、部分cropは全文採点しない。
同じ画像/モデル/複数cropの診断であり、独立資料数や製品精度改善として数えない。
confidenceの高い候補やnative比率内でも退行するか、外側の画線が本当に本文かを別に確認する。

先に未被覆画線の境界、重複和集合、白紙/閾値、不正RGB、移動/拡大/順序のテストをRed化する。
診断の結果を読んだ後、具体的な採用方針が見つかれば次の仕様と失敗テストを先行して検証する。
全文候補の一律追加やtruth最良候補の選択を既定へ入れない。

診断の集計層も結果を見る前に固定する。①全文前景を含む・native以内・検出帯1本・
既存非空出力がある・未被覆画線が正・candidate confidence>=.9、②それに既存出力の
非空白文字数で重み付けした平均confidence以上を加えた層を、originalとbands別に報告する。
両層とも各候補を独立に比較し、真値で候補を順位付けしない。各退行を全件残し、
この層で非悪化でも全287画像/CLI経路の検証を省かない。
JPEG元画像とPNGを別デコーダで比較する代わりに、同じRust decoderで全342cropの画素同一を検査する。

## 初回診断後の追加層（集計前）

736本文組・1368候補を確認した。固定.9の層では退行はなかったが、対象の100モデルは
原画像confidence=.893、既存断片平均=.737で、文字距離9→4になる候補まで除外していた。
単なる閾値の互換性で既知の欠落を残さず、固定floorを付けない相対confidence層も全候補で調べる。
native/帯1本/非空出力/未被覆画線/全文被覆の条件は同じで、candidate>=既存平均だけを追加する。
これは追加集計の仕様であり、製品への採用条件は別に全287画像で検証する。
