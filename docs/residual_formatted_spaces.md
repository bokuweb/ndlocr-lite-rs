## 先行仕様

固定済み混在書式の原寸画像で、6行目の `background color Color` と
14行目の `bold italic text` を保持する。正解・モデル・文字集合は変えない。
最初に固定PARSeqの区間別出力と連結空白属性を記録するRedを追加し、画像の

## 原寸Redと候補仕様

- 6行目1944×68: 境界483の空白幅20。字間1–5、広い空白15–31の分布で、
  31が15の2倍を超えるため従来閾値21を維持していた。
- 14行目1907×76: 境界1441の空白幅18。字間2–7、曖昧な幅12が1個、
  広い空白15–30。15が行高の1/5切上げ16に届かず、曖昧な幅も旧条件を外す。
- 両方とも各区間の認識は正しい。分割位置の選択は変えず連結属性を検証する。

少なくとも6個の支持が残る場合、広い群の最小幅をそのまま採らず、
`max(群の最小幅, 行高の1/5切上げ, 群の最大幅の1/2切上げ)` まで閾値を上げる。
これにより短すぎる幅や広がり過ぎた群は取り込まず、既存の絶対下限と2倍の
広がり制限を維持する。通常字間から2倍以上離れた群に6個以上の支持があれば、
間にある曖昧な幅1個は群から除外する。その曖昧な幅自身を単語空白とはしない。
3–5個の支持しかない場合は既存の厳しい条件を維持する。全角行と字形余白の
除外条件は変えない。
