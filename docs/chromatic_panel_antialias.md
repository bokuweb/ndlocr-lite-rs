# 色パネル外縁のアンチエイリアス

## 実装前の仕様（2026-10-18）

回転・再標本化で色背景と白紙を混ぜた外縁を、白文字として反転すると
字間を横断する黒い線になる。背景除去の対象に、この外縁だけを追加する。
正解文字列・既知の回転角度・文書ごとの置換は使わない。

対象は既存処理が推定した色パネルの上下端。各列で、背景に接する外側が
白紙で、その間が最大3画素の背景色と白の線形混合（RGB各成分の丸め誤差3以内）
になっていることを確認する。隣接列で端の位置の差が1画素以内、背景成分差が
24未満の状態が既存の背景標本の最小幅 `max(width/4, 64)` 以上続く場合だけ、
その薄い混合部分を白にする。途中に混合画素がない列も連続性の支持に使う。

文字・罫線を守る条件:

- パネル内部の白文字・黒文字・異色の文字を従来どおり暗い字形として保持する。
- 境界と背景1画素以上で分離された短い白文字のアンチエイリアスを消さない。
- 内側の白い細線（背景を行全体から分断しないもの）と、端にある黒・異色の細線を保持する。
- 独立した色文字、細線、無彩色ページを変えない。
- 元画像・寸法・座標は変更しない。追加依存は導入しない。

白紙と接し、背景と白の混合だけからなる長い外縁の画線は、再標本化による
境界と画素だけで区別できない。この形状を持つ装飾線の意味保存は保証しない。
外縁へ直接つながる白い画線も、この曖昧さを持つ。全幅の白線で色パネルが
二つに分断される既存の制限は別課題とし、この修正で対応したとは扱わない。
任意の写真・縦方向グラデーション・3画素より広いぼけも対象外とする。

最初に人工画像で傾斜した上下端・混合率・位置を固定し、失敗を確認する。
既存のパネル・文字色・ラグ状端の全対照を通してから、凍結済み10枚の
傾き評価を再実行する。傾き補正自体の採用可否は元の採用基準を維持する。
