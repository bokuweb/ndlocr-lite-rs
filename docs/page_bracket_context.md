# 改行の断片に含まれる閉じ括弧を保持する

## 実装前の仕様（2026-10-19）

既知4資料のCLI比較で、神戸市資料の短い継続行 `り1.2)。` と、NDL資料の
`国立国会図書館）が作成しました。` 等の閉じ括弧が失われている。
同じcropの生PARSeqと既存sanitize結果を先に比較し、入力/モデル側の欠落と区別する。
真値・モデル・検出・crop・confidence閾値は変更しない。

`sanitize_recognized_text` は従来APIとして挙動を維持する。
新たな `sanitize_recognized_fragment` は同じ空白/反復処理と既存置換を使い、
閉じ括弧だけは対応する開き括弧が同じ断片にないことを理由に削除しない。
文字の挿入・括弧の推測・文書固有置換の追加は行わない。既存の文書固有置換を
増やさず、今回の差分は括弧の削除方針だけに限定する。

ページの行を認識するCLIとPageRecognizerはこの断片方針を使う。
ParseqPoolは既存のロード/セッション選択/バッチ処理/推論回数を維持し、内部の
復号後処理だけを選べるようにする。既存の単行Session/Pool/recognize APIの
方針は維持し、PageRecognizer::from_poolsにもページ用方針を適用する。
raw APIを変えず、confidenceも後処理で変更しない。

単体Redと括弧種類/ASCII本文のPBTを先に固定する。実画像ではrawが括弧を持つことと
既定CLIがそれを保持することを検査する。固定4画像×既定DEIM/明示bandsの全8組で
none/width/strictの文字距離非悪化を要求し、合計で退行を相殺しない。
改行の異なる別資料・未知資料での一般化は今回の開発回帰から保証しない。

## 追加の初回対照（推論前）

4資料での初回比較後、処理方針と閾値を変えずに、気象庁2025-03-26の
https://www.jma.go.jp/jma/press/2503/26a/ccj2025.pdf の1ページ目本文を追加する。
ロゴ・表紙図版を除く本文範囲を描画確認後に固定し、抽出真値とhashを保存してから
両版を推論する。気象庁と同じ発行元だが、列挙・囲み・URLの別内容を含む対照とする。
4資料の結果を根拠にこの新規対照向けのパラメータや処理条件は追加しない。
ページ範囲と真値は推論後に都合よく変更しない。モデル学習との重複は不明である。

## 初回対照と検証状況

初回の4資料・2設定は全24指標非悪化。固定方針のまま追加した気候変動資料も、
DEIMは生61→60 / width50→49 / strict24→23、bandsは63→62 / 52→51 / 23→22。
5資料・2設定の全30画像別指標が非悪化。変更した6組の本文は閉じ括弧の挿入だけで、
他4組はbyte同一（`cli/character-edits.json`）。モデル出力に存在する文字を保持した結果で、
正解を使った括弧推測は行っていない。新資料も初回観測後は開発回帰として扱う。

通常/ONNXの並行ビルド時に、CLI試験が共用targetのonnxなし実行ファイルを参照し、
後者が途中で失敗した。失敗ログを残し、通常ビルド完了後にONNX binaryを再リンクして
ONNX全対象を順番に再実行する。モデル試験の失敗を精度退行とは混同しない。
プール1呼出しの推論は同じだが、CLIのcascade長閾値を括弧保持後に判定するため、
本文長が境界にあれば全ページのモデル呼出数が変わりうる。速度・総推論数は未測定。


## 最終の回帰と再現

通常482件、実モデルを含むONNX対象387件が成功。公開Poolのscalar/batch/single-session
batchの旧本文・順序・confidence・不正入力後の再利用と、ページ並列処理の追加5件も成功
（前記387件の一部再実行を含む）。fmt/diff、対象Clippy成功、未変更箇所の既存17警告。
ONNXなし実行ファイルの参照による途中失敗は順次再実行で解消した。A/Bの20プロセスは
別名へコピーした固定binaryを使っており、このtarget衝突の影響を受けていない。
凍結truthと再現手順は `docs/benchmarks/page-brackets/README.md`。
