# 原寸行に残る単語空白の評価

前回固定した段落14行と色背景38行には、`nibh, nunc` と `Introduction The` の
空白1文字ずつが欠落する。正解を変更せず、公開 `ae0fe43` の分割区間と固定モデル出力を
記録し、入力画像上の単語間隔の判定とモデル内の空白欠落を分離する。

- 元ページ全体を既存の背景正規化に通した後、保存済み座標で原寸cropする。
- cropと出典・座標・SHA・正解を `tests/fixtures/residual_spaces/` に固定する。
- 全行と各chunkの出力、境界空白属性を観察し、全文一致をRedとする。
- 幾何条件を変更する場合は境界/PBTと既存全文コーパスを検証し、差し引き悪化は採用しない。
- モデルの候補を正解で選ぶ処理、文書固有置換、空白除去による成功扱いは追加しない。

この2文書は既に調整に使用した開発データであり、汎化の証明には使用しない。

## 原因と試行

基準では段落の13列、見出しの12列の空白を、代表字幅23から求めた14列の閾値で除外していた。
各chunkのモデル出力はそれぞれ正しい単語で、欠落は文字列連結時の空白属性による。
段落の字間は1〜6列・単語間隔12〜15列、見出しは1〜3列・単語間隔10〜15列と分離する。

比例幅の行（代表幅が行高の2/3未満）で、字間群が過半数以上・大きい空白群が3個以上・
両群間が2倍以上・大きい群の最大/最小が2倍以下・最小が行高の1/5以上の場合だけ、
その最小実空白と既存字幅閾値の小さい方を使う。十分な支持と明確な分離がない行では従来値を使う。
原寸2行の認識は空白を含めて完全一致した。

最初の試行は分割候補の優先度まで変更し、既存描画28領域の誤りを6→8文字に悪化させたため不採用。
モデル入力の区間選択と末尾統合は従来の字幅閾値で維持し、確定した境界の連結空白だけを
実間隔の分布から再判定する。原寸2行の分割座標を固定するRedを追加する。

## 検証

原寸2行は分割座標を維持して空白を含めて完全一致した。連結空白だけを補う変更で、
追加候補推論やモデル・文字集合の変更はない。拡大1〜3倍・左右padding 0〜11列のPBTを含む。
従来の字体別28領域は6/588、スキャン6領域は0/117を維持した。
通常247件・ONNX対象189件、両構成all-target Clippy（既存警告のみ）、fmt/diffが成功。
