# 行投影で欠けた単独字形の外端を戻す

金融文書の折り返し見出し末尾「せ」は原寸で39px高だが、下端の画素行が
投影の閾値に届かず、検出範囲は30px高になった。下部8pxを欠いた入力では
PARSeqが「十一」と認識する。原寸画像と出典を `tests/fixtures/truncated_glyphs/`
に保存する。この文書は既に開発データであり、独立評価とは扱わない。

通常行の中央値より短く、幅も文字数個以内の既存行だけを候補にする。
隣行に重ならない近傍を走査し、既存範囲と重なる文字寸法・密度の8近傍成分が
上下へ続く場合だけ全高を戻す。走査端へ続く罫線、矩形、別行、小点は採用しない。
復元した横書き字形には公式PARSeqの縦書き回転を避ける背景余白を含める。
上下の背景余白は通常文字高の1/8とする。全高を戻しただけでは「七日」等となり、
密着した外端を避ける余白も必要だった。既に全画素を含む短い行は変更しない。
文字置換とモデル変更は行わない。

Redは原寸「せ」の全高保持と実PARSeq認識。連結した罫線・隣行・孤立ノイズの
負例、移動と画像境界のPBT、naive/fast一致を加える。既存全文と領域corpusを
同じ正解で評価し、誤りが増える変更は採用しない。
