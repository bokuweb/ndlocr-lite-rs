# 高密度な横長行の短すぎる初回結果を再確認する

## 診断と実装前の候補

固定120文字和文の4変形は、100モデルで2/3/3/8文字の後にLowConfidenceで停止した。
停止直前の選択確率は0.13〜0.29で、既存デコーダの0.35未満条件に該当する。
最初の数文字の平均confidenceは最大0.93で、平均値だけで欠落を判定できない。
同じRGBを既存の安全なchunkへ分けると30/50/100の全モデルで4例とも完全一致する。
デコーダの閾値や文字置換を変えず、100モデルによる局所入力の再認識を試す。

次を全て満たす準備済みcropだけを対象にする。

- 行高12px以上、実モデル入力比率の2倍を超える横長RGB。
- 初回結果は0〜16文字。
- RGB平均220未満の前景が幅の1/3以上の列にあり、全体の前景高さが行高1/2以上。
- 幅2行高以下・高さ1/3行高以上の前景列群が40以上、かつ初回文字数の4倍以上。

既存 `split_line_for_input` / `crop_line_chunk_rgb_u8` で実モデルの入力寸法に応じた
2個以上のchunkを作り、同じpoolへHorizontalを明示して再認識する。
全chunkが非空・finite confidence 0.9以上1以下で、連結結果が元の2倍以上、
支持列群の1/2以上の文字数を説明し、英数字/CJK等のalphanumeric文字が4種類以上ある
場合だけ候補を採用する。空白挿入は既存規則に従い、confidenceは出力文字数で重み付けする。
失敗/不一致なら元結果を維持し、元RGB・bbox・生モデル/単行APIは変えない。

CLIでは既存の長行再認識と同じ100モデルpoolを使い、`--split-long-lines false` なら再確認しない。
PageRecognizerは供給された同じモデルで再確認し、別モデルへ切り替えない。
既存Pool APIはAutoのまま、新しい内部経路だけHorizontalを明示する。

## 先行テストと全件ゲート

適用条件・境界値・不正RGB・推論失敗/低confidence/短すぎる候補・反復記号・
呼出し回数・元画素/候補文字保存を例示とPBTで先にRed化する。
PoolのAuto/Horizontal、生APIとの一致、エラー後の再利用も固定モデルで比較する。

新しい和文・別字体/太さ・JPEG75/半分PNGを処理前に固定する。
広い白紙、罫線、単色矩形、孤立ノイズ、密な短い横棒、縦棒群、広く離れた短文、
反復文字/数字も全件対照へ含める。語句や画像IDで対象を選ばない。
元の46画像と追加対照を全件使い、CLI DEIM/bands、PageRecognizer 30/100それぞれで
none/width/strictの画像別文字距離が非悪化となり、対象長行で厳密改善することを要求する。
候補条件を対照ごとに調整しない。退行があれば案をそのまま採用しない。
これは既知/合成/機械変形の開発回帰であり、未知実資料や全反復文字の保証ではない。

検出cropが元行の先頭を切っている例では、可視部分の復旧とbbox保存を検証する。
全幅真値の完全一致を検出cropへ要求せず、全ページの文字距離で欠落も計上する。

## 初回案の棄却とページ文脈の保護

初回の79画像比較では、100モデルの `japanese_mincho24` と
`dense_library_maru24_half` が各2文字退行した。同じ行を覆う、IoU 90%未満の
2検出を両方復旧してしまうため。30モデルの27改善だけでは採用しない。

追加認識の前に、選択済み領域をページ全体で確認する。別領域との交差が
小さい方の面積の50%以上なら、両領域とも高密度再認識を行わない。
検出の採否やbbox/既存長行処理を変えず、曖昧な重複を追加文字で増幅しない。
無効bboxも対象外。境界50%、接触のみ、別行、包含、入力順・拡大・平行移動を
先にRed化し、CLI/PageRecognizerで共有する。真値や認識語句は渡さない。

## 固定比較の結果

修正版は79画像×CLI DEIM/bandsとPageRecognizer 30/100×none/width/strictの
全948文字距離が非悪化。316本文の65組が3正規化すべてで改善、他251組はbyte同一。
CLIでは既存20画像40本文は同一。30モデルのPageRecognizerでは既存資料7変形も改善した。

bandsの和文2例は生117→0、119→0/各120文字。DEIMの和文3例は118→12、
114→16、117→9。別の1例は重複検出のため元の短い結果を保つ。
全幅ROI診断の4完全一致を、crop後の4完全一致と取り違えない。
36pxのbands2例などは条件/候補confidenceを通らず、短いまま残る。

単語指標は空白区切りで、6本文組がnone/widthで退行した（12指標）。
PageRecognizer100の生単語誤り合計は690→691/997語。
採用ゲートは先行仕様どおり画像別文字距離であり、全指標の非悪化とは主張しない。
raw/width/strictの全指標・元本文と退行一覧をbenchmarkに保存する。

既知資料・機械変形・独自合成による開発回帰であり、未知実スキャンでの汎化は未確認。
追加推論があり、並行実行の所要時間から速度向上を主張しない。
実行の指定・初回案・採点と再現手順は `docs/benchmarks/dense-line/README.md` を参照。
