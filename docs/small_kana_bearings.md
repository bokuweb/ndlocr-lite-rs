# 小書き仮名の余白と単語空白を区別する

別文書の初回全文評価で「スレッド」が「スレッ ド」となった。
原寸行を `tests/fixtures/small_kana_bearings/thread.png` に固定し、
分割位置・空白判定・実PARSeq入力を先に検証する。
短く小さい字形は通常の仮名より左右の背景余白が多い。
細い縦棒だけでなく、このような字形の寸法も使って実空白と区別する。

文字認識後の置換や空白削除は行わない。実際の広い単語空白、
曲線括弧の空白、漢字部品の保護、字形数/幅制限は維持する。
反転・平行移動・境界のプロパティと既存全文corpusで回帰を検証する。
本画像を選んだ時点で元の別文書も開発データとして扱う。

## 判定と回帰

行全高に対して中央値の字幅が2/3以上の場合に限り、字幅が中央値の3/4以上、
行高の3/4以下、インクの全高が行高の2/3以下の字形を対象とする。
左右背景余白は `(行高 - 字幅) / 2` を切り上げて推定し、従来の
単語空白閾値との比較前に差し引く。狭い欧文の行・全高字形は対象外。
これは文字種認識ではなく形状からの推定であり、すべての混植や書体での
精度を保証しない。

原寸fixtureは1527×47px、中央値35px、「ッ」は幅32px・全高29px、
後方の白列25px。Redでは分割後に `スレッ ド`、Greenでは同じモデルで
`スレッド安全性が保証されます。さらに様々な種類のバグをコンパイ` と一致。
合成画像の25px字間/50px実空白、狭い欧文/全高字形の実空白、原寸画像の
背景追加・左右反転32ケースを検証する。実モデルテストはCIでも実行する。
