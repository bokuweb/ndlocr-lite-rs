# 同じ文字集合の信頼度を比較する空白支持G

## 解析・実装・追加認識前仕様

Fは比例送りの実空白11本文組を消して棄却した。画像・truth・Fの選択と全候補を保存する。
元結果の平均confidenceはASCII空白の確率も含み、空白を除いた候補とは異なる文字集合の平均になる。
空白の確率が低いだけで本文の根拠が強くなったと扱う可能性を、別案Gとして検査する。
以下の条件は元本文の非空白確率を調べる前に固定する。

- GはFの全条件を維持した部分集合とし、画像支持や閾値を調整しない。
- 元デコードで実際に出力した文字のうちASCII空白以外のpmaxだけを、元ステップ順のf32加算と
  f32除算で平均する。EOS・低信頼度で未出力の停止ステップは含めない。
  Unicode全角空白や他の文字をASCII空白と同一視しない。
- 3候補は元本文からASCII空白1個だけを除いた同じ文字列なので、その既存平均を本文平均として使う。
  **全3候補の平均が、元の非空白本文平均をそれぞれ厳密に上回ること**を追加要求する。
  元非空白平均が存在しない・非有限・範囲外なら元結果を保持する。
  返すのは従来と同じ先頭の実モデル候補で、confidenceを書き換えない。
- 既存4,022入力の元ROIを凍結したwhole ROI exporterで再認識し、全12,066組の本文/f32平均が
  保存された元結果と一致することを確認してから、その実stepから非空白平均を得る。
  原NN結果との不一致は調査し、許容誤差を後付けで広げない。
- 既存4,022入力の全実候補へGを適用し、全件を公式none/width/strictの文字/単語距離で比較する。
  既知の失敗例だけを除外せず、1件でも退行があればGを採用しない。
- 新たな共通対照は `作業内容、確認先` / `実施日時。連絡窓口`、ASCII空白0/1/2個。
  同じCoreText3字体、18/30px、`palt=0/1`、横60/90%、上下紙0/10px、PNG/JPEG75の全576入力。
  同じ描画/原画素/必要文字/実font/送りとwhole ROIの検証を認識前に行う。
  新条件を見てGの条件・閾値・画像・truthを変更しない。
- 合計4,598入力×3モデル×3正規化の41,382文字/単語指標で非悪化、かつ距離改善があることを要求する。
  ページの回復を維持できるかは別途検査し、維持できない場合も事実を報告する。
- 採用する場合、同じforwardの既存decode observerから非空白平均を取得し、余分な元ROI forwardを追加しない。
  公開RecognizeResultの構造・raw/候補API・既存平均の演算順序を変えない。
  非空白平均の例示/境界/PBTと、見かけの全体平均だけが上がるcallback反例をRed先行で検査する。
- 全件のRust製品選択replay、影響入力と実空白負例の全単行API、単行CLI・ページ8経路を比較する。
  同じSessionを使い、追加forwardはFと同じ最大3回、失敗時は元結果を保持する。

既知fontの合成開発対照であり、確率の校正や未知実資料への汎化は仮定しない。

## 結果: Gも棄却

旧4,022入力の元ROIと新576入力の4候補を合わせ、全18,978 forwardが正常終了した。
実際の6326 forward入力RGBを保存・照合し、旧12,066組の本文とf32平均は保存結果と全て一致した。
元の非空白平均の取得で別の原入力やデコーダを比較した測定差はない。

固定条件Gの4,598入力・41,382文字/単語指標では、各64指標が退行した。
内訳は既存4,022入力の6本文組、新576入力の26本文組、計32組。
全体平均から空白を除いても、原モデルが出した実空白を守れなかった。
122文字距離改善・79完全一致回復も保存するが、退行と相殺せずGを棄却した。
GはRustの製品経路へ実装していないため、GのRust製品replayや公開API実測とは称さない。

失敗例には、もともと正しい空白1個を消す例と、空白2個を1個と読んだ元結果からさらに空白を消し、
文字距離1→2へ悪化させる例の両方がある。旧Fが回復したページ由来の30モデルpinもGでは選択されなかった。
同一入力のGはFの部分集合であることと、既存4,022入力ではFの判定が当時のRust選択と一致することも確認した。
Fの4,022入力とGの4,598入力は母集団が異なるため、退行の件数だけで両案の優劣を比較しない。

自動余白再認識の製品撤去は `docs/punctuation_space_rejection.md` の先行仕様に従う。
