# 幅が行ごとに変わる色背景

## 実装前の仕様

公開基準 `8fd60e2` は、長いハイライトの末尾行だけ短い場合に、上の行の背景がある列を
下の行にも適用する。列ごとの背景中央値に対し、下の行の白紙を白文字と誤認して黒くする。
実文書では `[154,1723,2334,1796]` の末尾行に黒い長方形ができ、
安全な白列分割が存在せずページ全体の認識が失敗する。

各行の色背景の左右端の外側は原画素を保持する。左右端の間の白文字・黒文字は
従来通り背景に対する明暗差で変換する。横方向のgradientへの列別中央値は維持する。
全幅を横切る線や細い色文字をパネルとみなさない既存条件は変更しない。
空の色行と無彩色ページは変更しない。追加推論・文字列置換は使わない。

Red: 長い上部と短い末尾行の合成パネルで、外側白紙・内側白黒字形の画素を固定する。
実文書の原寸領域でも正規化後に末尾行の空白が残り、安全に分割できることを確認する。
PBTで末尾行の左右端と高さを変え、行外画素の不変条件を確認する。
全文精度はomo側で、推論前に固定した2文書と既存全コーパスを比較する。

## 隣接する別色の背景

左右端の保持でエラーは解消したが、全文は20行2295/3517誤りとなった。
緑と黄色の隣接パネルを一つにまとめ、列中央値と異なる背景色が暗く残り、複数行を連結している。
各行の色画素の中央値輝度を比較し、背景差だけで既定閾値220未満の画素になる色変化では
パネルを分ける。各パネル内の横方向gradientは従来の列中央値で処理する。
合成した隣接2色の背景と実ページの38行分離を先にRedへ追加する。

単純な行中央値の比較は、gradient上の文字が一部の列を隠すだけで中央値が変わり、
既存見出しの安全な分割を壊したため棄却。色変化による分割は、既存の背景認定と同じ
十分長い連続色画素を持つ行に限定し、字形による分布の偏りを背景変化とみなさない。

実ページで色分割後も長い行の外端が暗く残った。列の背景サンプルがパネル高さの半数以下だと
未処理にする条件が原因で、短い行が多い段落では長い行の背景を保持してしまう。
行ごとの範囲を既に限定したうえで、色背景サンプルが存在する列を正規化する。
長い行が少数でも背景を残さない合成Redを先に追加し、既存の細い色文字保持も再検証する。

## Greenと評価上の制約

合成3件・実画像2件・行外画素PBTがGreen。既存のgradient、白黒両極性、細い色文字、
薄い罫線、無彩色ページの借用も維持した。固定ONNXで短い末尾行の原文を完全復元する。
omo全文は38行・1/3517誤り（内部空白1文字欠落）。普通の段落は14行・1/1316で変化なし。
本文・座標と初回推論前に固定した正解・SHAはomoの `ocr_highlighted_accuracy` と
`ocr_paragraph_accuracy` fixtureに保存する。初回公開基準はページ全体でエラーとなり
本文を返さないため、CERの相対改善率は定義しない。

色付き写真、任意の図版、縦方向のgradientの補正精度は保証しない。
修正選択に使用した文書であり、未知文書への汎化やproduction readyの証明ではない。
