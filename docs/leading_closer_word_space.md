# 先頭閉じ括弧の後ろの単語空白を画線から回復

## 実装前仕様

比較元ae42fce。前段の1527画像でraw正読を後処理で壊す330本文組のうち、新対照41組は全て
先頭closer＋ASCII空白＋ABC/DEFで、`） ABC` → ` ABC` 等になる。元1271の289組も残る。
末尾の空白回復を維持し、対称な先頭の局所gapを確認する。文書語句やcloser種類の推測置換はしない。

候補は、既存の括弧除去結果よりfragmentが長い・実効横書き・有効RGBの場合に限る。
先頭1個が既存5種closerで、その後のASCII空白0/1個を除く本文が3字以上、本文にはwhitespace/他closerがないことを要求する。
空白を除いた文字列と独立成分数が一致し、x重複がなく、従来または本文整列の支持が必要。
本文側の隣接gapが2個以上・各gap>0・4*max_gap<=本文最大高さを要求し、
closer幅>=ceil(本文高さ/4)・closer高さ<=2*本文高さも要求する。
先頭closerと本文のgapが max(2*本文gap最大+ceil(本文高さ/8),ceil(本文高さ/3)) 以上かつ本文高さ以下なら
元closer＋ASCII空白1個＋元本文を選ぶ。これは末尾と同じ閾値で、評価に合わせた探索はしない。
支持がなければae42fceの本文を維持する。prefix/internal/multiple、非ASCII/二重空白はこの条件以外では保持方針を変えない。
RGB/confidence・text-only/raw/候補API・page fragmentを維持し、追加モデル/forwardなし。

既存データは探索用。候補出力を見る前に、KLM・丸ゴシック/明朝・24/36px・5closer・prefix/suffix・
ASCII空白0/1・PNG/JPEG75の160画像と、左側の細/高い縦罫線（幅1/2・gap2/10・高さ22/66・2形式）の16対照を固定する。
truthは印字文字列（罫線は含めない）。canvas幅は高さの2倍以上でAuto回転による除外を防ぐ。
176のfixture Red→Green後にのみOCRする。既知fontの合成開発対照で、未知実資料holdoutではない。

test-only候補のRed→Greenを先行し、gap/幅/高さ・文字形式・RGB/方向、拡大/移動/明度PBT64例を検査する。
既存1527+176=1703画像×3モデル×3正規化=15327の文字/単語指標でae42fce比の全件非悪化を要求する。
既存rawをSHAと全before/fragment照合して再利用し、新176はraw/processed各528 forwardを新規捕捉する。
候補が通れば製品Red→Green・全5109の実Session再認識、全変更＋新176のCLI前後比較で確認する。
Cascadeの空白加算と25/45字境界は純粋テストで確認するが、実モデルの切替を伴う実画像の精度や未知資料汎化を主張しない。
原画像/真値/全本文/成分/確率/停止理由・正式評価表・失敗案・source/binary/input/model SHAを保存し、別rootで再採点・モデル不要の全件再生を確認する。

## 対称化候補を棄却した後の第2候補（評価前追記）

第1候補は185本文を変え、108文字・262単語指標で退行した。
`）ABC` にraw `) ABC` が出る例では、先頭括弧の細い画線から本文まで19px空いていても、
それは全角字幅の右側の余白である。本文gapだけでは語の空白と区別できないため、対称化案を製品へ入れない。

第2候補では第1候補の全条件に加え、先頭closer画線の左端から本文画線の左端までのadvance
（closer幅＋gap）が本文最大高さ以下であることを要求する。
先頭のmarkとgapを合わせて本文の字高1個に収まる、狭いadvanceの支持だけを扱う。
閾値は字高そのものを使いgrid探索しない。全角字幅を持つcloserと隣接空白の曖昧さは残り、完了扱いにしない。

第2候補評価前に、PQR・丸ゴシック/角ゴシック・18/32pxのprefix/suffix・5closer・空白0/1・PNG/JPEG75の160画像と
左側罫線16対照をさらに固定する。前の176を後付け変更しない。
全1879画像×3×3=16911の文字/単語比較でae42fce比の全件非悪化を要求する。
rawは旧1703×3を再利用、新176はraw/processed各528 forward。製品適用後は全5637の公開APIと全変更＋新対照の前後CLIを検査する。
