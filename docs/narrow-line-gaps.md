# 狭い行間の横書き見出し

通常行高を推定できる複数行のあるページで、2行高以上の候補に薄い水平の谷があれば、谷が1pxでも上下に本文相当の連続インク高がある場合は分離候補とする。
成分探索上限に到達する場合は分離しない。局所8近傍成分が谷を接続する場合も原則保持する。ただし1〜2pxの谷で、ピークインク数が通常高の8倍以上あり、接触成分の幅がそれぞれ通常高の2倍以下、合計幅がピークの10%以下なら、広い2行の少数文字の接触として分離する。孤立した縦画や幅広い単一字形は保持する。日本語や文書固有の語彙では判定しない。

先行回帰: 気象庁のロゴ除外本文で見出し2行が1帯に結合する。各見出しの中央行が異なる帯に含まれ、各帯は他方の中央行を含まないこと。naive/fast両経路で一致すること。
合成回帰: 細い汚れを含む1px行間は分離し、同じ投影でも上下を結ぶ縦画がある1文字は保持する。異なる通常高と汚れ位置をPBTで検査する。

公開pin統合前に既存実文書コーパスの全文・記号・正読対照を比較する。画素被覆や局所テスト成功だけで精度向上を主張しない。
