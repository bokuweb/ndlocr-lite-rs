# 分割区間の左右の文脈余白

## 着手前の仕様と仮説

公開基準 `df447a4` の記事続頁24行目は、原寸296×44の末尾区間を
純白列7/2pxだけ除去すると `to C/C++.[38]` が `toC/C+++.[38]` に悪化する。
同頁26行目の `the Code of` は左右cropで改善しているため、その改善も保持する。
原画像、座標、SHA、生出力をfixtureへ固定し、両方の全文期待を先に検証する。

調査では入力幅の1px差でも非単調な出力変化がある。文字列に特化した置換や
認識候補の正解による選択は採用しない。第1候補は、現在のcrop条件を保ちつつ、
左右に高さの1/24（切り上げ）以下の既存純白余白を残す方法である。
24px高モデルの入力に約1pxの文脈を確保する仮説で、追加推論は行わない。
画像外に画素を追加せず、全非白画素・内部空白・上下寸法・回転方向を保持する。
純白余白が足りない側は元の区間端で止める。未分割/短い/疎な区間は従来通り保持する。

Red: 原寸C/C++の固定モデル期待と、左右の既存白余白を残す幾何テスト。
Greenの採否はC/C++だけでなく既存全文と領域の全コーパスを比較して決める。
現在のコーパスは開発データであり、未知文書への改善は別途評価する。
候補が差し引きで悪化した場合は棄却し、試作を除去する。

## 第1候補の棄却と第2候補の仕様

1/24高の余白保持は、英文1 22→26、金融75→76、混在31→30、英文2 22→20。
和文140/836・106/863、句読点96/627、Rust5/357、領域6/588・0/117・9/91は維持。
差し引きで2文字悪化するため採用しない。試作コードと候補固有の幾何期待は除去する。

第2候補は、削る純白列の総幅が高さの四分の一未満なら元区間を保持する。
画線より十分大きい余白を除く従来の目的を保ち、小さな側部余白による再拡大を避ける。
原寸C/C++の9/44高は保持、Codeの15/46高は除去対象を維持する。
これは開発データを用いた幾何条件候補であり、モデルのリサイズ感度そのものは解決しない。
Redは削除幅9/10/11・高さ44の境界と同じ実モデル回帰で確認する。

## 採用する動作と評価

削る白列の総幅が高さの四分の一未満なら元の区間を返す。
既存の単語境界・幅5h以上・非白列群9以上・回転保持の条件は維持する。
元の画像の画素だけを用い、文字列置換・追加推論・モデル変更は行わない。

基準df447a4との全文比較で、英文続頁は22→20/2307、単語誤り16→14/352。
原寸末尾区間は296×44の文脈を保ち `to C/C++.[38]` に戻る。
中央の `the Code of` は231×46の切り出しと完全一致を維持する。
英文1 22/2269、金融75/473、和文140/836・106/863、混在31/326、
句読点96/627、Rust5/357、領域6/588・0/117・9/91、色ヘッダー2/17は維持する。
開発データで選んだ条件であり、独立した文書での精度改善の証明ではない。

モデルの入力幅に対する非単調な感度は残る。より汎用的な改善には、
独立文書の固定正解と、モデル側での余白・リサイズ変化への耐性評価が必要。
