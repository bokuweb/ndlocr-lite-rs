# 候補exportの実入力保存

候補順位だけで誤認識を説明せず、推論に渡す同じRGBを再検査できるようにする。
`export_parseq_candidates --chunk-input-dir NEW_DIRECTORY` を明示した場合だけ、
通常の分割・crop後、認識APIへ渡す直前のRGBを可逆PNGとして保存する。
背景処理前のページや、モデル内部のresize後tensorとは区別する。

- 新しいディレクトリだけを受け付け、既存ファイルを上書きしない。
- ファイル名は連番。行IDはJSON内に保存し、パスとして解釈しない。
- `inputs.json` に実モデル入力寸法と各PNGの行ID・区間番号・行内x範囲・RGB寸法を保存。
- RGBは長さと寸法を検証し、そのまま保存する。白余白、淡い画素、文字を変更しない。
- 保存指定なしでは既存の出力と推論回数を変えない。保存自体も推論しない。
- 途中失敗では部分保存が残り得る。`inputs.json` は全推論成功後に作成する。

先にRGB往復、パスを含むID、既存ディレクトリ拒否、不正RGB拒否、任意RGBの
往復PBTをRedにする。既知の引用符・括弧3帯を30/50/100モデルで比較し、
同一区間のRGB同一性と生本文の再現を確認する。これは原因調査であり補正精度の改善ではない。
