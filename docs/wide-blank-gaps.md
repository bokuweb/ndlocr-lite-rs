# 広い完全白余白を挟む短文の安全な認識区間

## 先行仕様

公開42aa144では空白の中央だけを候補とするため、空白525〜1161pxを挟む
正立ラベル6件が分割を拒否する。原文による訂正や字形の再描画は行わない。

- `split_line` の全列を一度ずつ覆う契約は維持する。
- 認識用 `split_line_for_input` は既存の成功結果を保持する。
- 従来分割が失敗し、行高×8より広い **RGB全チャンネル255** の内側余白が
  ある場合、余白の左右に半行高（切上げ）の文脈を残して独立区間を作る。
  その各区間へ既存のモデル寸法・字形数条件を適用し、元座標へ戻す。
- 認識区間から省けるのはこの完全白余白の中央だけ。全非白RGB画素は元の座標で
  ちょうど一度保持し、白だけの中間区間をOCRへ渡さない。
- 分離後の先頭区間は元の余白幅を `gap_before` に保持し、連結時は単語空白を
  一度だけ補う。部分区間が分割不能なら全体を拒否し、部分成功を返さない。
- 閾値より明るくても非白である点・色・細線を省略しない。縦書きAPIは維持する。

## 先に固定する検証

合成2/3群、奇偶余白、縮尺・平行移動・RGB色のPBT、既存成功との一致、
薄い非白点、連続する分割不能字形、実失敗6帯で、順序・幅・語間・全非白画素と
元座標を検査する。実モデルでは既存28画像の全文を同じ原文・候補で比較し、
失敗を0編集や空文字に置き換えず、悪化は採用の不合格として残す。
