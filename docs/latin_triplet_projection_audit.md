# 英字3文字とcloserの接触構造の読み取り専用監査

## 実装・分類前の仕様

比較元はd711eec。凍結した全162,915組から、rawと真値が一致する一方で製品本文が異なり、
本文がASCII英字3文字、端のcloserが1個、空白なしの4 scalarとなる組を記録する。
これは既知の残差を調べるための抽出であり、将来の支持条件や未知資料の評価を決めるものではない。
同じ(width,height,元RGB SHA)をまとめても、全モデル・条件・方向の参照を保持する。

元RGB・寸法・SHAを照合し、既存collectorと同じRGB和660未満を前景として、
8近傍でつながる全成分を記録する。小成分の除去や字形group化は行わない。
各成分のbbox/面積、各行・列の前景数、前景が1個だけの列とその元座標を保存する。
原画素の削除・補間・文字列変更・新しいNNは行わず、Rust製品collectorの再測定とも区別する。

小さな3ブロックと2つの1画素接触、8近傍の斜め接続、RGB和659/660、
不正寸法/RGB長、入力不変性、鏡映・channel順序の性質を先にテストする。
監査結果だけで文字境界が確定したり、精度が改善したとは扱わない。
支持器を作る場合は、別の先行仕様と失敗するRustテスト、既存全件と追加対照の非悪化を必須とする。
