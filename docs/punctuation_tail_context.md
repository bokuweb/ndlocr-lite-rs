# 分割先頭へ孤立した上下の小画線

## 仕様（実装前）

固定モデルの15行目は、単語内境界で区切られた次区間が小さい上部記号と下部記号で始まり、続く単語空白を落とす。元画像の2画線は高さの半分より小さく中央の帯をまたがない。前区間に戻すと認識できるが、従来の短い末尾処理は左区間の開始が単語内、空白幅が高さ1/5未満のため対象外。この既存条件は緩めない。

追加候補は、次の確認済み単語空白までが回転対象の短い幅に収まり、上部・下部に離れた小画線があり中央の帯が白い場合だけ。各側に3画素以上、各bounding boxは縦横とも高さ1/2未満、上端は高さ1/8以内、下端は高さ3/4以降を必要とする。単語空白幅は既存の字形内境界回避にも使う高さ1/10以上。通常文字、i/jの軸、全高の括弧、単独の句点は対象外。

前区間と残り区間が水平、モデル入力比率と列群数上限を満たす場合にだけ白列内へ境界を移す。元画素・区間数・ページ座標・全画素被覆を維持する。文字列置換や追加推論は行わない。

固定モデルRed、合成Red、保護条件、拡大/移動PBTを先行し、既存の斜体句点回帰と全コーパスで採否を判定する。これは開発データの改善候補であり汎化・production readyを証明しない。

## 実画像で確認した空白支持

最初の候補は固定モデルで改善しなかった。実画像の次の空白は10列だが、細い小画線のbearing補正でword_space=falseとなっていた。全行の既存word_spaceが3件以上あり、その幅の中央値以上の原画像空白に限り、小画線形状と合わせて境界候補を復元する。支持が不足する場合や中央値未満は移動しない。この限定処理は既存の一般空白推定を変更しない。

中央値でも実画像はRedのまま（既存幅24,16,16,17,11,14,17,8,23,15、候補10列）。斜体では句読点直後の空白が通常の字間より狭い。三件以上の確実な空白がある行に限り、その最小実幅を下限として使う候補を別のRedで評価する。形状・高さ1/10・列群上限などの保護は維持する。
