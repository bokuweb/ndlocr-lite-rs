# 上点と本文stemでLatinの認識済みround closerを支持する

## 実装・追加NN前の仕様

比較元はe42eb19（最新文書f31a87dも同じRust）。純粋ownerの11テストと無除去readerの
4テストを先行した。保存1,069元RGB・2,830参照・4,808成分は独立抽出と一致し、
1,020画像で幾何的な点所有が成立した。これはmarker/文字位置との対応や精度回復ではない。
ownerの条件は6386307740cd222df614960fb56c47c4485db726b195e1fa81d5a53e02bae495で固定した。

次の候補もtest-onlyとし、全件比較と別途先行する新対照が終わるまで製品へ接続しない。
既存の高さ/部品/ページ断片の判定は変更しない。文字追加、空白変更、RGB/NN/mean変更は行わない。

- textはASCII英字3〜8字と端のround closer（半角/全角）1個。空白なしで、小文字i/jが
  1〜2個あることを要求する。単語の一致は使わない。他closer/内部closer/複数closerは対象外。
- 全元前景をreaderで回収し、3画素未満の成分があれば拒否する。端成分をmarkerとして分け、
  残りの最大成分高をHとする。Hは8以上。面積filterで点や島を捨てない。
- 本文stemは高さ3H/4以上H以下の成分で、数が本文文字数と一致する。
  それ以外は点で、高さH/3以下、数が小文字i/jの個数と一致する。中間の高さは拒否する。
- 各点へ固定ownerを適用し、唯一の所有stemが文字順でi/jに対応し、同じstemへ2点が
  付かず、全i/jへ1点ずつ付くことを要求する。接触した2本文の分割は行わない。
- 全stemは幅ceil(H/8)以上floor(3H/2)以下、面積max(3,ceil(H/2))以上。
  x順で重ならず、隣接gapはceil(H/4)以下。共通の縦区間は2H/3以上、
  下端の最大差はceil(H/3)以下。点を本文高/共通区間へ混ぜず、ascender/descenderを明示的に扱う。
- 全成分それぞれのbbox内の元前景数がその成分面積に一致することを要求する。
  全前景の所有が一意で、他成分の画線をbbox内へ混ぜない。
- markerは本文の外側にありgapはceil(H/4)以下。高さMHは3H/4以上3H/2以下で、
  本文の共通縦区間を完全に覆う。幅MWはmax(3,ceil(MH/6))以上floor(MH/3)以下。
  既存narrow profileの寸法条件を緩めず、この新候補だけで別の幅範囲を検査する。
- markerは全行に1個の連続前景区間を持ち、各行の前景幅はceil(3MW/4)以下。
  最上/最下行は左半分内、中央行は右半分から右端までである。
  中央を含む右半分内の連続帯はceil(MH/3)行以上。最右列への到達は中央行に要求し、
  帯の全行が最右列に到達することは要求しない。前景面積もmarkerの所属と一致する。

実装時の仕様補足：最初の実装は既存narrow profileにならい、帯の全行へ最右列の到達も
要求していた。maru40pxの丸括弧では最右列は12/38行だけで、点所有が正しくても拒否した。
右半分を連続して通る曲線と、中央行の最大x到達を別に検査する。8近傍で繋がる曲線の
頂点が2行だけの例を先にRedで固定してから、この過剰な条件を修正する。数値境界と
固定ownerは変更しない。既存の製品narrow profileも変更しない。追加NN前の補足であり、
初回のsource・失敗ログ・仕様も保持する。

既知のAgjp40px prefix/suffixを画素同一fixtureとして使い、点除去/追加/所有違い、
接触qj、本文/点/markerの寸法・上下配置・間隔・島・誤った輪郭・文字条件をテスト先行で検査する。
境界/PBT後に数値条件を凍結し、旧223,143組を全て同じraw/真値で比較する。
方向は現在の製品gateを保持し、Autoで回転する元RGBをこの候補で救済しない。
正式none/width/strictの入力別文字・単語退行があれば採用を止め、反例を保存する。
追加NN結果に合わせて条件を再調整しない。
