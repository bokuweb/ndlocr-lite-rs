# 追加実資料の事前固定と誤り診断（新しい認識前仕様）

既存の坊つちやん/羅生門と既知font合成対照に偏らないよう、別の公開スキャンを調べる。
この段階は追加資料の選定と正解文の固定までとし、進行中FVB全件gateへ途中で入力を加えない。
Q/Sは既存先行gate未達の保留を維持し、この資料の存在だけで保留を撤回しない。

- 一次の所蔵館記録、画像/IIIF manifest、公開範囲とrightsを保存する。
  インターネット公開かつ公開再配布に使える画像を選ぶ。認証が必要な資料は採用しない。
  既存二冊以外の二資料を目標とし、使えない候補と理由も残す。
- OCR出力を見ずに、最初の連続本文ページの右端から完整な本文3列を選ぶ。
  表題/柱/頁番号を除き、原スキャンのRGBを単純cropする。文字を落とすcrop試行は保存して棄却する。
  原画像/URL/取得日時/response/ページと矩形、PNG/RGB SHAを固定する。
- GTは画像にある本文の旧字/仮名/句読点を転記し、Rubyは画像に残して本文GTへ入れない。
  Unicode曖昧字が解決できなければ認識前に複数の採点表記を固定し、全表記で非悪化を必要とする。
  同じ担当による二度の目視確認を独立した人間注釈と呼ばない。専門家注釈/学習未重複は主張しない。
- source/Cargo/model/charset/入力/GTと実行物SHA、既存凍結binaryの再利用理由を認識前に保存する。
  GTや文書名をNN入力・補完条件へ渡さない。追加NNはFVBの進行中比較を整理してから実行する。

後続の診断ではPage30/50/100のeval/defaultとCLI DEIM/bandsを全件測る。
FVBを採用した場合は新しい本体を基準にし、未採用ならOを基準にする。事前に実際の基準を明記する。
モデルload/外側API/画像結果と内部forwardを分け、未測定はnullとする。
公式none/width/strictと独立距離を照合し、誤りを検出・crop・容量・不確実文字・空白などに分類する。
この新しい誤り観測の後に別の改善案/Red/Green/未測定対照/gateを固定し、
既知例だけへの訂正や新規検証のない閾値調整を本体へ入れない。

本文単列GTでは組版の字下げや字間を空白scalarへ推測変換せず、画像にある本文字列を転記する。
句読点と列末の途中の語も保持し、列外の続きは補わない。字体が判別困難な場合の別表記は、
モデル観測前に列ごとに列挙し、いずれも固定した採点IDとして残す。
