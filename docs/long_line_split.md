# 長行の中央再分割で字形と単語空白を保持する

## 現状と先行評価

CLIの80文字以上・幅高4倍以上の再認識は、RGBの幅を無条件に半分へ切り、
左右の認識を空白なしで連結する。中央が字形上なら字形を二つに割り、
単語空白上ならsanitizerのtrim後に空白を失う可能性がある。
これまでの固定20画像の全100モデル結果は最大77文字で、この分岐を通っていない。

実装前に、独自に記述した長文4種（英文2・和文1・長いURI1）と短い対照2種を、
角ゴシック/明朝、24/36pxで全24画像へ描画し、真値・PNG・font/image SHAを凍結する。
長いURIは下線ありとする。さらに既存の実段落crop2種（原/背景処理済み）を使う。
全26画像をモデルが読む前に固定し、認識長、中央の画素、既存CLIの全出力を記録する。
これは合成と既存開発資料の回帰であり、未知資料holdoutではない。

## 候補（実装前）

既存の80文字閾値と幅高4倍を維持し、中央の±行高の範囲で最も近い内側の
白列群へ切断位置を移す。既存のblank-gap分類で字形内部と判定された狭い間隔は避ける。
元の中央が適格な白列群の中なら同じ座標を維持し、それ以外は白列群の中央を使う。
距離同点は小さいxを選ぶ。外周紙へは移動しない。

近くに適格な白列がない場合、既存の支持条件で確認した薄い下線だけを分割判定用コピーから
外して同じ探索を行う。認識RGBには元の下線を含むすべての画素を残す。
それでも候補がない場合は初回認識を保持し、字形を横断する二分をしない。

既存の単語空白分類と連結規則を共有し、境界が単語空白の場合だけ左右の間に空白を戻す。
左右cropは元RGBを欠落/重複なく覆い、上下座標を変えない。
cached/legacyの長行再認識で同じ幾何方針を使い、文章固有の判定や語句置換を加えない。

幾何・負例・下線・不正入力・元画素被覆のPBTを先にRed化する。
採用は全26新規対照と既存20画像のDEIM/bandsを全件比較し、各none/width/strictの
文字距離非悪化かつ長行で厳密改善を確認してからとする。退行があれば案をそのまま採用しない。

## 初回候補の退行と境界保持の修正（実装前）

全46画像の初回比較は4指標で退行した。明朝36pxの英文で、原の中央は
連結画線を切っておらず、旧処理は全文正読だった。候補は近い白隙間を
狭い字形内部として除外し、再認識自体をやめて100文字の不完全な初回結果を返した。
したがって「元の中央が既に安全なら維持」を連結画素でも検証する必要がある。

元の中央に8近傍の前景連結が横断していなければ位置を維持する。
ただし左右両側の前景を要求し、外周紙/白紙だけの二分はしない。
新しく移動する候補では、引き続き内部字形の狭い隙間を除く。
下線は既存の支持条件で確認した判定コピーで同じ検査を行う。
この修正の根拠と初回の退行を保存し、真値・画像・80文字の条件は変えない。

## 重複抑制との分離と最終結果

安全な原境界を保持する追加2 Red→11件Greenの後、同一クラスの近似同一DEIM領域で
strict 1指標の退行が残った。重複抑制を長行処理から切り離して先に検証し、
それだけの独立版8edefcdで全276文字指標が非悪化になることを確認した。
その独立版を比較元にして、長行境界の変更だけを再評価した。

新26+既存20画像のDEIM/bands、全276文字指標が非悪化。
15本文が厳密改善し、他77本文はbyte同一。既存20画像の40本文は同一だった。
bandsの下線URIは1→0文字、実段落crop2種も各1→0文字となり、正読対照も維持した。
26入力のモデル診断では、従来の12連結画線切断が0件になった。

通常518件・ONNX対象435件、fmt/diff/対象Clippyが成功（既存17警告）。
新たな単語置換や辞書選択はなく、認識RGBの画素は左右で欠落/重複なく保持する。
判定の前景閾値はRGB平均220未満。原境界を保持する場合、既存の非連結部品間の
意味的な切れ目まで分類して直すとは主張しない。

比較元の92本文は、直前の独立版の全実行からSHAを照合して凍結再利用し、
候補92プロセスを新規実行した。初回/修正候補の退行、全出力/真値/コマンド/SHAは
`benchmarks/long-line-split/` に保存。既知・合成の開発対照で、未知実資料の保証ではない。
長い和文4変形は初回認識が2〜8文字となり、この80文字分岐の手前で崩れる。
次はその入力情報量とearly-stopを診断する。
