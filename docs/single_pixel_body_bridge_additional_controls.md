# 次の追加対照による1画素接触案の再監査

## 新しい認識結果の分析前仕様

`docs/detached_body_components.md` で固定した10,944画像は、本文2字間のASCII空白も含む。
その追加NNは進行中で、まだ本文や候補選択を分析していない。
この同じ新対照を使い、既定へ接続済みの1画素接触案もdb25206と比較する。
新しい本文、画像、truth、閾値、組合せやNNの回数は変更しない。

- 同じ全32,832 rawと原RGBを、接続前の凍結した実Rust方針と現在の0127fe8方針へ通す。
  前者のtest-only診断が予測した1画素接触後の出力も、後者の実製品出力と全件照合する。
- 正式toolでnone/width/strict、文字と単語を全件比較し、平均の改善で個別の退行を相殺しない。
  新しいdetached-body案とは別のbaseline・別の監査として扱う。
- 1指標でも退行すれば、その反例を回帰テストにして接続済み案の採用を再検討する。
  同じ追加結果へ閾値を合わせ直さず、必要なら接続を撤回して別の独立対照を使う。

これは追加NNではなく同じ保存rawの方針比較。新しい独立画像数へ重複加算しない。
