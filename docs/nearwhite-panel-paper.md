# 外周につながる近白紙（実装前の仕様）

完全白だけをたどる外周探索では、色文字との補間画素 `[255,254,254]` が経路を遮り、外側の白紙が黒い細片になる。既存の白紙保護を、各成分が250以上の近白まで拡張する。これはJPEG全般の補正を保証するものではない。

- RGB各成分が250以上でページ境界へ4近傍接続する画素を、元RGBのまま保持する。白への塗り替えはしない。
- いずれかの成分が249以下の画素、斜めだけの接触は探索の経路にしない。
- 色背景に囲まれた近白字形は従来どおり暗くする。
- 色背景のない画像は借用のまま返す。
- 小寸法と色・形状の変化をテストし、画素単位探索との比較も維持する。

境界につながる近白字形も保護されるという曖昧さは残る。固定28画像で全文・行分離・座標・原画素写像を比較し、悪化を隠さない。新しい独立資料での精度や速度向上は局所テストだけから主張しない。以前の完全白仕様と測定結果はその時点の記録として保持する。
