# 英字本文内の1組の接触を分ける支持用kernel

## 実装前の仕様

比較元はd711eec。読み取り専用監査の67モデル/条件組・27元RGBでは、24画像が3成分、
3画像が4成分だった。例示のKLMではLとMが1画素列で接触し、XYZではXとYが接触する。
別に外接矩形だけが重なる例もあり、本kernelはそれらを扱わない。
これは既知の開発用残差で、新規NNや未知資料の精度測定ではない。

まずprivateなtest-only kernelを実装する。文字列・marker・NNを受け取らず、元成分bbox内の
bool mask、幅/高さ、本文高を受け取り、支持用の2つの成分viewだけを返す。
元maskを変更せず、実際のRGBや認識区間から画素を削除しない。

- 本文高は6以上。bbox高は本文高以下で、その3/4以上。寸法/長さをchecked演算で照合し、
  bbox面積65,536以下、幅は3×本文高+1以下で探索量を制限する。
- 端以外の列を左から調べ、前景1画素だけの列を候補とする。
  その画素は左右の隣接列の前景へ、それぞれ8近傍で接している必要がある。
- 支持用maskからその1画素だけを一時的に除き、左右それぞれに8近傍成分が1個だけあることを要求する。
  全前景の所属を確認し、2 viewの面積の和+1が元面積に一致する。孤立部品を捨てない。
- 左viewは元左端とcut直前まで、右viewはcut直後から元右端までを覆う。
  両viewの幅は本文高の1/2以上・3/2以下で、広い方は狭い方の2倍以下。
  各高さと共通の縦区間は本文高の3/4以上である。全viewを合わせた上下端も元bboxと一致する。
- 最初に全条件を満たす候補を返す。満たす候補がなければNone。
  長い1画素接続で複数のcutが成立しても元RGBは変えず、文字位置や意味の一意な推定とは扱わない。

小さな正例をRed→Greenにした後、太い接触・未接続・切断画素の孤立・小部品・余白/不正形状、
幅比/高さ/共通区間/探索budgetの境界を小さい単位で追加する。
鏡映・接続行の移動・寸法変化・入力不変性をPBTで検査する。
marker条件や文字列の適用条件は別仕様で固定する。本kernelだけで製品へ接続したり精度改善を主張しない。
