# タイル分割の行検出（opt-in）

## 目的
行検出（DEIM）は入力を 1024×1024 に縮小する。300 dpi の官報のページ（3509×2480 など）を 1 枚で検出すると、小さい字の行が
隣の段の行とつながった 1 つの枠になったり（「…土井卓哉44富安亮太法務省告示記第百五十七号」）、見出しの行が検出されなかったりする。
ページの一部だけを切り出して検出すると、同じ行が正しく分かれて検出される。

## 仕様
- `recognize-page --detect-tiles N`（既定 1）。1 なら従来どおりページ全体だけを検出する（結果は変わらない）。
- N≥2 のとき、ページ全体の検出に加え、ページを N×N の格子に分け、各タイルを隣のタイルと重ねて（タイルの幅・高さの 1/8）
  切り出して検出し、枠をページの座標へ戻す。
- 統合（`merge_tiled_detections`）:
  1. タイルの検出のうち、ページの縁でないタイルの縁に接するもの（行がタイルで切れている）は捨てる。
  2. ページ全体の検出のうち、面積の大半を中に持つタイルの検出に、互いに重ならないもの（別の行）が 2 つ以上あるもの（複数の行を
     つないだ枠）は捨てる。同じ行の断片（「公示送」「送達」）は重なり合うので数えない。
  3. 残ったページ全体の検出の中にほぼ収まるタイルの検出は、その行の断片として捨てる。
  4. 残りを合わせ、重なり（IoU）の大きい組は確信度の高い方だけを残す。
- 字の補正や語の辞書は使わない。枠の幾何だけで決める。

## Evaluation (lawrenceanum kanpo census, 157 items)

`--detect-tiles 4` vs default: 4 items fixed (missed small headings recovered),
3 regressed (tile-split lines changed reading order around headings); net +1.
Kept opt-in (default 1) for that reason.
