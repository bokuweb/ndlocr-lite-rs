# 仮名内部の白列で字形を分断しない

Rust紹介文の原寸行（1637×47px）では「が」の画線間に4pxの白列があり、
従来の行高1/20以下という部品間判定を外れていた。x=975で分割すると
`でメモリ効率カ` / `高く` となり、認識前に字形の右側を失う。

仕様を先に固定する。実空白を優先する既存挙動は維持し、実空白候補がない場合、
均等分割点に最も近い白列が従来の1/20以下、または行高1/10未満かつ
前後のインク列群と白列の合計幅が行高以下なら、行高以内にある1/10以上の
白列を選ぶ。幅/字形数の制限と、後続区間の分割可能性を守る候補だけを使う。
近傍に広い白列がなければ従来の安全な白列へ戻す。文字列置換は行わない。

原寸fixtureの「が」全幅が同一区間に残る幾何テストと、固定PARSeqが
`メモリ効率が`を認識するテストをRedにする。合成画像では1/10未満/以上の
境界、近傍に候補がない場合、画像の左右反転・平行移動で分割不変条件を確認する。
omoの全文・金融・領域corpusすべてで回帰を検証する。この文書は開発データであり、
未知文書への改善を保証しない。
