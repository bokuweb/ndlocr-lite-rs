# 連結書体の明確な単語空白群

独立した `bold-italic-emulation.pdf` の真値を先に固定して427文字中17編集のRedを確認した。通常・擬似太字の連結した英字で、成分幅中央値が行高の2/3を超え、全角行を保護する早期除外へ入る。単語間白列も全て除外され、単語途中の境界で擬似太字の `font:` がモデル出力から抜ける。原寸区間を実単語空白で分けると同じモデルで認識する。

全角相当中央値の保護を維持しつつ、連結成分が一つ以上あり、白列幅の上半分に5個以上の群があり、その群の最小幅が小さい群の最大幅の2.5倍以上で明確に離れる場合だけ例外を設ける。高さ1/5以上・最大間隔の半分以上という既存下限を保ち、絞った後も3個以上の支持を要求する。疎な空白、連結成分なし、分離不足、極端な群内幅差は除外する。認識文字列や書体名には依存しない。

まずこの分布の合成Redと拡大PBTを追加する。最小変更でGreen後、固定モデル・独立資料・既存全資料を比較する。退行する条件は採用しない。

## 追加観察: 5空白の通常書体

通常書体行の空白は5個（幅11,11,12,13,14）で、字間の最大4から2.75倍離れている。6個の支持ではこの行を除外するため、強い2.5倍分離の場合の支持を5個へ広げる。4個以下・連結なし・2.5倍未満は引き続き除外する。先にこの5個境界のRedを確認する。

## 区間選択の先行Red

強い空白群を認識しても従来の優先境界を保つため、擬似太字・斜体では単語内の境界が残る。全角中央値の早期除外を超えた強い空白群に限定し、同じ保護済み閾値を区間の優先境界にも使う。元の全角保護を通る通常経路の境界は変えない。固定モデルで擬似太字2行を全文比較して先にRed化する。

## 弱い傾きで確認できる空白

擬似斜体の投影スコア改善は10.83%で、既存の20%閾値に達しない。元の画素を変えず、投影で単語空白と確認できる元画像の白列が6個以上ある場合だけ10%以上の改善を受理する。20%以上の従来経路は維持し、10%未満・6個未満の支持は除外する。傾き判定を文脈分割へ流用しない。実行前に未加工画像の空白フラグのRedを追加し、拡大・移動・反転と直立の保護を検証する。
