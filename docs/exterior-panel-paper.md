# 色パネル外側の白紙（2026-10-18）

段差・凹形状の有彩色パネルでは、同じ行の背景両端を結ぶ区間に外側の白紙が含まれる。従来の背景正規化はこれを白文字として黒へ反転し、字間・行間を塞ぐ。文字列・書体・既知角度には依存せず、背景正規化の段階で防ぐ。

実装前に固定する期待:

- ページ境界へ4近傍で接続する完全白RGBだけは元のまま保持する。斜め接触だけでは接続しない。
- 同じ色背景で囲まれた白文字・白い穴は暗い字形へ変換する。
- 外側の黒・灰・色文字は変更規則を追加しない。近白や白との補間画素を新たに白へ塗り替えない。
- 形状・位置・色を変えるPBTで外側白紙と内部の白/黒文字を同時に検査する。
- 無彩色ページの借用・既存画像回帰を維持する。既存のantialias処理は維持する。

幅×ページ高の訪問マスクと非再帰の行区間探索を使う。適用は既存の色背景検出が成立した帯に限る。全文精度・時間は別途固定モデルで比較し、局所テストのみで採用判断しない。

限界: 外側と同じ完全白で接続する白字形は画素だけでは区別できない。境界につながる白は保持する仕様であり、その経路の文字回復は保証しない。JPEG等の近白紙は今回対象外。
