# 多段組みOCRの欠落・重複改善（2026-10-23）

## 対象と完了条件

lawrenceanum/docs/ndlocr-tesseract-handoff.txt の固定条件に従う。
Phase 1–3の既存I/O・推論を保持し、Phase 4の段分離と読み順、Phase 5の比較を進める。
比較対象はTesseract.js 6.0.1 / pinned tessdata_fast jpn / LSTM / PSM3 / DPI300。
既知2 cropは開発用。別ページから画面で転記し、推論前に固定した段/全ページ正解で
CERが比較対象以下、本文欠落・重複・読み順の回帰なしを目標とする。
未達を達成扱いしない。外部辞書、正解依存の語句置換、GT改変を行わない。
lawrenceanumの既定や未コミット変更を変更しない。

## 1. 診断（先行仕様）

`recognize-page --trace-json PATH` は任意のJSON診断を別ファイルに保存する。
指定の有無でTXT/stdout/推論選択を変えない。schema_version=1。
画像寸法・設定、DEIMの行候補、検出失敗/無効/空の区別、fallback選択、
補助抽出の候補と画線判定、認識crop（bbox・cascade bucket）、認識結果
（既存finish後、confidence/空文字による採否）、context整理前後、
missing-context回復後、最終読み順と最終本文を保存する。
認識cropに対応しない候補は領域選択/無効bbox段階で除外されたものとして区別する。
診断はモデル内部forwardやdecoder stepを表すものではない。
出力の親directoryを生成し、書込失敗は通常のCLIエラーにする。

## 2. 汎用構造処理（実装前に詳細を追加）

段の検出は画素の幾何だけを使い、ページ名・文書種類・正解文を参照しない。
既存単段、縦書き、句読点・長行の回帰をテストする。
高閾値への一律変更は行わない。重複と段分離を別のテストで扱う。

## 3. 評価

生出力・SHA256・argv・全試行・失敗を保存する。評価のみNFKC+空白除去。
全ページの文字数は被覆精度と呼ばない。独立した段/全ページGTを主指標とし、
先頭末尾、番号順、重複、欠落を併記する。速度/RSSは逐次・release・新processの
同じ測定境界で3反復し、診断を無効にする。精度と速度を混ぜて評価しない。

### 段分離の先行条件

横書き段分離は画像全高で暗画素のない縦の余白を使う。幅は少なくとも
max(12px, image_height/120)、外側余白を除き両側の区画幅はmax(80px,image_width/10)
以上を必要とする。各区画で従来抽出を独立に実行し、少なくとも3本の横長行
（幅が高さの3倍以上）がある場合のみ段として受理する。
成立しなければ従来単段処理をそのまま使う。画線を跨いで分割しない。
段が成立したときは段ごとのY投影から行を取り、元画像座標へ戻す。
読み順は受理した段の左→右、段内は既存の読み順を保持する。
空白のない画像・単行・縦書き・語間空白・短い左右注記は段としない。
DEIM閾値の既定は変更しない。段のないcropの重複対策は別に扱う。

### 採点レポートの先行仕様

公式 `tools/eval_ocr_metrics.py` のLevenshtein距離を使用し、NFKC+空白除去した
採点用コピーだけを渡す。生出力を保持する。ハッシュ不一致は拒否する。
追加診断として編集列の挿入/削除/置換、正解物理行の過剰な完全重複数、
先頭末尾24文字の一致、告知番号列の一致を報告する。
本文の同じ定型文が正解にも複数回ある場合は重複誤りに数えない。
反復ごとに採点し、テキスト決定性と時間/RSSを別集計する。

### 横書き段内の1文字行

確認済み横書き段には、折返し末尾の数字1文字や句読点だけの行もある。
矩形が縦長というだけで段順を破棄したり、その行だけ段頭へ移動したりしない。
段内の短い行（高さが幅の3倍以下）は段の横書き順序に従う。
本当に長い縦列が混在する場合は従来の方向別順序を保持する。

## 4. DEIMが部分的に残る場合の構造選択（追加の先行仕様）

独立確認の初版では検出0.9でも14行が残り、fallbackが発動しなかった。
単に閾値を上げて空にする設定には依存しない。検出閾値0.25の既定を保ち、
以下の画像支持があるときは候補を認識する前に、確認済み横書き帯を選ぶ。

1. 既述の全高空白・各区画3本以上の横長行で2段以上が成立する。
2. 単段でも3本以上の横長帯があり、少なくとも別々の2帯で
   DEIMの完全行と、その内部に重なる短い行断片が競合する。
   完全行はconfidence>=0.5、帯の横幅の3/4以上を覆い、
   子候補はconfidence>=0.25、親幅の3/4以下で親の横範囲内にある。
   両者の上下端は帯から帯高の1/4以内。無効矩形・非横書き候補を根拠にしない。

それ以外のDEIM経路は保持する。単行の語間空白、近似同一bboxだけ、単一の曖昧な
重複、縦列は帯への切替根拠にしない。文言・名前・正解文字列を参照しない。
切替理由をtraceへ保存する。confidence除外によって被覆不足を隠さない。
修正に使った追加ページは開発用へ移し、別ページの未使用段で最終確認する。

単段の断片競合による切替は、全帯の高さが最小帯高の2倍以下の均一な行だけに限定する。
巨大な複数行領域と短い見出しが混ざるページを、2見出しの重複だけで全帯へ切り替えない。

モデルを使うCLI trace回帰は既存の実モデルテストと同様に通常はignoredとし、
固定モデルを取得するCIの必須CLI段階で明示実行する。モデルなしの通常テストに
新しい実モデル依存を持ち込まない。
