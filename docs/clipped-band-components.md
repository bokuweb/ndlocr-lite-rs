# 切り出し境界をまたぐ字形の回収

行検出帯の境界で切れた8近傍成分を、明示呼出しの汎用APIで完結させる。
既存naive/fast検出の既定動作は変えない。原文・OCR結果・文書種別は参照しない。

入力はRGB、画像寸法、半開矩形の検出帯、閾値、最大拡張画素数。
帯/寸法/長さ/拡張量を検証し、不正入力はErr。0帯は空の結果。
最大拡張量は1以上、画像の長辺以下とする。0帯/全帯重複では全画像の探索領域を確保しない。
画像画素・帯順序・帯数は変えず、帯を縮めない。

元帯の境界画素から8近傍でつながる成分だけを調べる。
成分の実画素が複数の元帯に属する場合、元帯同士が重なる場合は回収しない。
成分の縦横サイズが最大拡張量の2倍を超える長い罫線等は回収しない。
各辺の拡張は指定量以内。新しい矩形に入る非白画素は、元帯か回収対象成分に限る。
隣接する独立図形を余白ごと巻き込む場合は元帯のままにする。
拡張後の別帯との矩形衝突は辞退する。原画素の重複を増やさない。

先行Redは左右/上下/斜めの実画線回収、近い独立図形、長い接続罫線、二帯にまたがる成分、
独立図形を包含する拡張、寸法不正とする。独立の座標集合oracleによるPBTを追加する。
同形の文字/図形の意味分類や、離れて欠落した丸ごとの文字回復は保証しない。
固定開発画像の全画素出典・全文認識・負例を比較し、汎化やproduction readyは別に検証する。
