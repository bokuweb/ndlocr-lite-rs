# 長行再分割の連結画線と単語空白

先行仕様 `../../long_line_split.md`。既存の80文字・幅高4倍の条件を維持し、
連結画線を切る中央だけを近い白列へ移す。既に連結画線を切っていない境界は保持する。
白列分類に裏付けられた単語空白を左右の認識間へ戻す。
下線は判断用コピーだけから外し、認識には元RGBを使う。

## 独立した最終比較

同クラス重複抑制だけのコミット8edefcdを比較元にした。
固定46画像（推論前に凍結した26長短行対照+既存20）×DEIM/bandsで、
none/width/strictの全276画像別文字指標が非悪化。
15本文が厳密改善し、残り77本文はbyte同一。既存20画像の40本文も同一。

例:
- bandsのlibrary_mincho36は2→0文字、下線URIのuri_gothic36は1→0文字。
- 既存の実段落crop原/背景処理済みは、DEIMで各4→2、bandsで各1→0文字。
- 正読だったobservations_mincho36は引き続き0文字誤り。

候補92プロセスを実行。比較元92本文は直前の独立した重複抑制版の実行結果を
model/charset/image/truth SHAを全件照合して凍結再利用した。新規実行とは数えない。
全前後本文・真値・6採点・実行argv/状態・各SHAは同梱した。

## Red / Green と棄却した経過

初回の入力診断では26画像中14が80文字条件を満たし、従来の中央が連結画線を
切る例を12件記録した（input-red）。同じ入力の最終モデル診断では0件。既知の下線行を元/候補の両方で同じように除外して照合した。
11件の幾何/境界/下線/不正入力/PBT、モデル診断2件、CLIの全文4ケースを検査した。
最終は通常518件、ONNX対象435件、fmt/diff/対象Clippyが成功（既存17警告）。

initial/は近い白列がない場合に再認識を中止した初回候補。
4文字指標で退行し、原の中央が安全な英文を37文字悪化させたため採用しなかった。
refined-before-dedup/は安全な原境界を保持する修正後だが重複抑制前の候補で、
薄い同一行の弱い重複領域だけにstrict 1文字の退行が残った。
これらの比較元はf9b2853の `../deim-same-class/before/`。
別に重複抑制を単独検証してから、その版を比較元とする上記最終比較を実行した。
未検証の二つの利益で退行を相殺していない。

input-red.logはhelper導入前の入力側のRed。幾何の未実装Red、
安全な原境界保持の追加Red/Green、各全件比較も保存した。
入力の再生は `tests/fixtures/long_line_split/manifest.json` の凍結PNGを使う。
初期診断の認識confidenceとDEIM検出スコアの取り違えは独立の重複抑制の資料に記録。
最終のdetected-crop/results.jsonは両方を別名で保存している。

## 制約と次の対象

既知資料/合成対照の回帰であり、未知資料の一般精度や高速化は主張しない。
濃度の判定はRGB平均220未満を前景とする。離れた字形部品の意味分類は保証しない。
和文の4変形は初回100モデルで2/3/3/8文字に崩れ、80文字条件を通らない。
この不足を隠さず、次に入力密度とearly-stopの原因を分離する。

棄却した2候補の全出力/採点/metadata（初回helperソースを含む）は、各ディレクトリの
`evidence.zip`へ可逆保存した。archive.jsonにZIPと各memberのSHAを記録し、復元一致を検証。
例: `unzip docs/benchmarks/long-line-split/initial/evidence.zip -d /tmp/long-line-initial`。
最終採用版の前後本文は通常のディレクトリのまま直接読める。
