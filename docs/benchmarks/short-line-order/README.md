# 短い横書きのモデル合意

先行仕様 `../../short_horizontal_line.md`。
30文字モデルの低信頼度・2〜4文字・幅高2〜6倍の結果だけ、50/100の合意で
再確認する。両モデルの高信頼度・全文一致・元の文字multiset一致を要求する。
文字を生成/並び替えず、採用候補の実際の出力を使う。

## 全文A/B

`manifest.json` の2実行バイナリSHA・20入力画像SHAを固定。
`runs.json` に80プロセスのargv/状態/時間を記録した。
元5資料と固定15変形を、DEIM/bandsの両設定で比較した。
元資料の前版と前回の全40本文がbyte一致することを `baseline-replay.json` に記録。
本文前後・真値・6採点CSV/Markdownをすべて保存。

気候資料の元画像とJPEG90の「昇上で」→「で上昇」だけが変化し、
DEIM/bandsとも各2文字改善。他36組の本文はbyte同一。
全120件の画像別文字距離（none/width/strict）が非悪化。
元画像DEIMは生60→58、width49→47、strict23→21 /800字。
JPEG75・半分PNGは本文同一で、改善したと扱わない。

## 合成対照

`tests/fixtures/short_line_order/manifest.json` の固定96cropも全件非悪化。
`synthetic-results.json` に元認識・選択結果・追加推論数を記録。
追加推論は1件で、選択された本文変更は0件。この集合は主に不適用/棄却の対照であり、
未知資料でのモデル合意の正しさを保証しない。生成スクリプトも保存。

## 制約

処理はCLIカスケードだけに適用。既存単行API、ParseqCascadePool、単一モデル
PageRecognizerの契約は変えていない。候補確認では最大2回の推論が増える。
補助モデル不一致/失敗では元結果を返す。速度改善や総推論数削減は主張しない。
これは既知資料と機械変形・合成cropの開発回帰であり、独立の実スキャンの検証ではない。
