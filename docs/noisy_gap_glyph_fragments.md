# 行間分離時の短い字形部品の保護

## 問題と範囲

通常行高が小さい本文と大きな見出しが混在すると、低密度の谷による追加分割が、大きな文字の短い横画を独立行として出す。空白を含む半開区間高だけでは通常行に相当する本文の存在を証明できない。

Arial Unicodeの30px本文2行と180px「二三ごニニ」の診断では、変更前の4帯から5帯へ短い帯が増えた。Noto Sans JP Regularでも同様の短い帯があるが、これは変更前から5帯であり新規回帰とは区別する。文字の内容を条件には使用しない。既存の行検出自体が大きな非連結字形を複数帯にする問題は別に残る。この変更で見出し全体を1行へ復元するとは主張しない。

## 先行する期待

- 追加分割の両側に、低密度谷を除く連続した通常行相当のインク高が必要。
- 正常行高30に対し短い15px部品と通常高の本文が疎な汚れでつながった領域は分割しない。拡大と移動でも同じ。
- 実フォント画像で、短い横画を増やす前の領域数・全文画素被覆を保つ。
- 本文5行の汚れ分離、実scaned0の7領域と固定モデル9/223編集を悪化させない。
- 連結筆画・成分上限・通常行高不足の既存保護を維持。画像や原文の置換、モデル/閾値調整はしない。

## 最小実装案

既存の推定通常行高に対し、候補の両側に通常行高の3/4以上の高密度連続行があることを確認する。短い成分数や文書固有文字列には依存しない。連続高さの条件はスキャンやフォントの開発例による保守的な条件であり、普遍的な字形識別を保証しない。
