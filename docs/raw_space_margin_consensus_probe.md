# 生出力の余分な空白を、余白候補の合意で直せるか調べる

## 推論前に固定する診断

前段では丸字体2区間の30モデルが左右2pxの純白追加で正読した一方、
100モデルには原入力が正読・左右1px追加が誤読でconfidenceも上がる反例があった。
ここでは「元が空白を出した場合だけ複数候補を確認する」案を別に検査する。
通常の製品処理・生APIは変更しない。採用済みの改善とは数えない。

- 元の2区間に加え、新規144入力を固定する。
  文は `予定時刻、担当者` / `実験条件、温度` の2つ。
  読点後のASCII空白0/1/2個、丸ゴシック/角ゴシック/明朝、24/36px、
  原寸/半分、PNG/JPEG75を全組み合わせる（2×3×3×2×2×2=144）。
  フォントの実ファイルSHA・描画真値・寸法・形式を認識前に保存する。
  font.getbboxの周囲に各2pxの白余白を置き、bbox原点を補正して描画する。
  半分はLANCZOSで縮小してから保存し、JPEGも保存後のRGBを読み戻して固定する。
- 各146入力の元RGBと、左右2px/上下0・1・2pxを加えた3候補を作る。
  全584区間をatlasへ画素そのままで配置し、既存candidate exporterの明示bboxで
  Horizontal認識する。30/50/100で各区間を1回、計1,752 forwardを記録する。
  各区間が分割されないことを確認し、区間RGBのSHAと元画素/純白追加の一致を検査する。
  atlas化はモデルの入力を混ぜる処理ではなく、各bboxを個別に切り出して供給する。

## 事前固定の選択案

- 元の生本文がASCII空白をちょうど1つ含み、他は仮名/漢字/和文句読点だけで、
  非空白文字数が6〜12のときだけ候補対象とする。文頭末尾の空白は対象外。
- 3候補の本文がすべて同じで、元本文のASCII空白だけを除いた文字列とも一致し、
  各confidenceが有限で.98〜1、左右2px/上下0pxのconfidenceが元より厳密に高い場合だけ選ぶ。
  選ぶ本文はこの実モデル候補そのものとする。
- 画像支持なしの案Aと、原RGBの220閾値による内部の完全白列群の最大幅が
  0より大きく行高の3/4以下であることを加えた案Bを、別々に評価する。
  両案を全件報告し、結果を見て条件や真値を変更しない。
- 公式scorerで元/案A/案Bのnone/width/strict文字距離と単語距離を比較する。
  実空白を消す退行は合計で相殺せず、1件でもあればその案の採用を棄却する。
- 全て既知区間と固定フォントによる開発診断。非退行でも、本番採用には別途、
  製品全経路の失敗テスト・全件比較・未知実資料の対照が必要。

## 第2段の実空白位置対照（第1段観測後・追加認識前）

第1段はAが84文字/84単語指標で退行し、Bは48本文組を正読に戻して退行0だった。
ただしBの対象条件は読点直後に限定していないため、読点後だけの対照では不十分。

- 同じ2文の読点後以外の全ての文字間にASCII空白を1つずつ挿入する。
  8文字の文は6位置、7文字の文は5位置、計11位置を対象にする。
- 丸ゴシック/角ゴシック/明朝の24px原寸PNGに限定し、各2pxの元紙余白と、
  さらに上下各2pxを追加した紙文脈を比較する（11×3×2=66入力）。
- 各66入力にも元RGBと左右2px/上下0・1・2pxの候補を作り、
  全264区間×3モデル=792 forwardを新規実行する。
- 第1段と同じA/Bを変更せず評価し、文中の実空白や紙余白で退行する場合は採用を棄却する。
  元の146入力・真値・候補・結果を編集せず、第2段を独立した開発対照として保存する。

## 第3段の紙余白と語間の対照（追加認識前）

第2段は両案とも退行0だったが、選ばれた33組は実空白の位置を誤った元出力の
距離を2→1へ減らすだけで、実空白を正読している対照を十分に説明しない。

- 第1段のASCII空白1個・24pxの24入力（3字体×2文×原寸/半分×2形式）に、
  上下各2・4・8pxの白紙文脈を追加する（72入力）。元の画素と真値は維持する。
- `東京都 神奈川県` / `資料分類 受付番号` / `特許庁 受付窓口` の
  語間のASCII空白1個を、同じ3字体・24px原寸PNG、上下追加0/4pxで描画する（18入力）。
- 合計90入力にも従来と同じ4条件を作り、360区間×3モデルを実行する。
  A/Bの選択条件は変更せず、正しい空白を消す例があれば棄却する。

## 最終判断

第3段でAは19本文組・38文字/38単語指標、Bも16本文組・32文字/32単語指標で退行した。
両案を棄却し、製品へ追加しない。none/widthが退行を捉え、空白を除くstrictでは隠れた。
最初のBの48完全一致回復や第2段の33距離改善だけを採用の根拠にはしない。

反例の「予定時刻、 担当者」はconfidence約.98695の正読が、約.99967の空白欠落になる。
原画素を保った紙余白追加で、画像高が14→18、字形の前景高と内部最大白列幅は12のまま。
画像全高を使ったBの幾何gateがfalse→trueになった。紙余白に依存しない画線高の支持は
次の独立した仕様/対照で検討し、ここで条件を調整して成功扱いにはしない。

3段階の302入力・1,208区間×3モデルの全候補、確率、RGB/atlas検査、公式表と
棄却例は `docs/benchmarks/primary50-and-spaces/`。既知字形の開発診断で、未知実資料の証拠ではない。
