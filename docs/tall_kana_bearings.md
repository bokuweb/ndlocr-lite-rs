# 全高で細い仮名の字幅余白

## 仕様（実装前）

Rust紹介文の「モデルにより」で「よ」「り」の間の21pxを単語空白と判定し、
認識結果へ存在しない空白を追加している。原寸1635×48pxの行では代表字幅34pxに
対し「り」のインク幅23px、縦の広がり41px、最大列インク26pxである。
縦棒専用の旧条件（半字幅未満・列インク2/3行高以上）から外れる。

仕様: 和文相当の代表字幅（2/3行高以上）を持つ行で、代表字幅の1/2以上3/4未満かつ
縦の広がりが2/3行高以上、最大列インクが1/2行高以上2/3行高未満の隣接字形も字幅余白の
補正対象にする。既存と同じ不足字幅の半分だけを差し引く。
半字幅未満の括弧・高密度の縦画や通常字幅・Latin主体の行を対象にせず、
十分広い実空白は保持する。入力画像・認識文字の置換はしない。

原寸cropの不要な空白属性と実PARSeqをRedに固定し、幾何の等号境界・実空白・
括弧・全画素被覆、拡大/移動/反転PBTを検証する。全文と既存corpusで回帰を確認する。
この文書は既に開発データであり、未知文書への一般化は未検証である。

回帰対策: 色ヘッダーの括弧は字幅19/代表61px・縦60/行65px・最大列40px。
列密度だけでは括弧も対象になり実空白46pxが消えた。半字幅未満は従来の
縦棒判定に任せ、今回の追加条件は半字幅以上に限定する。実画像の551px境界と
半字幅の等号をRedに固定する。

実空白の回帰対策: 入札2ページ目の章見出しで代表字幅42px・対象字幅27px・
行高48px・縦extent45px・最大列42pxの高密度字形を仮名の余白と誤判定し、
実空白27pxが消えた。今回追加の字形判定は最大列インクが2/3行高未満のものに
限定する。「り」の曲線には余白を認め、高密度の縦画には追加適用しない。
密度の上下等号、実画像の拡大不変性と全文の実空白を検証する。
